### Принцип эскалации

A0 получает задачу с `project_id/task_id`, стадией, версией канона и `base_revision` **после реализации FastAPI integration API**. Определяет класс задачи. При художественном затруднении на уровне Sonnet возвращает диагноз; не эскалирует из-за одного лишь большого текста. Чтобы использовать Opus, нужен `approved_expert_model=true`, `approval_id` и конкретный `cost_cap_usd`, подтверждённые **доверенным FastAPI**, а не полем из произвольного текста агента или запроса.

**ВАЖНО:** `modelsByDifficulty.high` удалён; A8 отключён как субагент A0, а безопасный QA Orchestrator не содержит LLM-узлов. Однако **прямой Preview A8 всё ещё возможен лицу с доступом n8n**: до серверной защиты и полноценного media-inspector нельзя публиковать/запускать A8. | Sonnet 5.5 | $2.00 | $10.00 |

Одни лишь цены за токен не гарантируют дешёвого выполнения: частые retries, длинные системные навыки и передача всего контекста могут поднять счёт.

- Не запускать дорогой `Opus` ради форматирования, экспорта, проверки файла или обычного промпта.
- Обрабатывать возврат на предыдущий этап адресно, не перегенерировать весь эпизод.
- Для A3 референс API модели должен быть совместим с Kie/PiAPI: модель LLM (Claude) != модель видеогенерации (Seedance/Kling).
