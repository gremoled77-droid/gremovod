# Облачный контур приёмки: n8n Cloud → туннель → студия

Дата: 2026-10-20. Источник workflow: `integrations/n8n/workflows/gremovod-qa-studio-loop.ts`.
Workflow в n8n Cloud: `GremoVOD — приёмка через студию (черновик)`, id `4YoGZBPw7SVXc1kg`,
адрес `https://gremovod.app.n8n.cloud/workflow/4YoGZBPw7SVXc1kg` (черновик, не опубликован).

## Что делает контур

1. n8n создаёт ревью в студии: `POST /api/qa/reviews`. Сервер сам считает ревизии артефакта,
   канона и брифа от содержимого (`sha256`) и возвращает `review_id`.
2. Каждому независимому критику выдаётся **изолированный пакет**: `GET /api/qa/reviews/{id}/packet/{role}`.
   В пакете только его роль, текст артефакта, канон, бриф и доверенные ревизии. Чужих вердиктов и истории в нём нет.
3. Вердикт критика уходит в студию: `POST /api/qa/reviews/{id}/verdicts`. Сервер проверяет ревизию,
   сверяет доказательство с доверенным источником и **сам** пересчитывает итог; в ответе — `server_receipt`.
4. Итог забирается из студии: `GET /api/qa/reviews/{id}`. Итог считает сервер, а не n8n.

Пока независимые критики A6/A7 не подключены, workflow отправляет честные вердикты `BLOCKED`
с указанием, что именно не подключено. Это осознанное поведение: «зелёный» статус без критика
не появится.

## Доступ к студии

Машинный токен студии, а не браузерная сессия:

- токены живут в окружении сервера: `STUDIO_SERVICE_TOKENS=<токен>:<проект|*>;<токен2>:<проект>`;
- токен открывает **только** `/api/qa/*` — генерация, медиа и настройки остались за сессией владельца;
- вне зоны токена — `403`, без токена — `401`;
- адрес студии должен стоять в `STUDIO_REMOTE_HOSTS`, иначе запрос с чужим Host отклоняется.

Проверено вживую через публичный туннель:

| Запрос | Ответ |
|---|---|
| `GET /api/health` без токена | 200 |
| `GET /api/qa/reviews/probe` без токена | 401 |
| `GET /api/qa/reviews/probe` с токеном | 404 (токен принят, ревью нет) |
| `GET /api/projects` с токеном | 401 (токен не открывает студию) |
| `POST /api/qa/reviews` с токеном своего проекта | 200 |
| `POST /api/qa/reviews` с токеном чужого проекта | 403 |

## Настройка в n8n (одно действие)

1. Создать credential типа **Header Auth / Templated Custom Auth** с именем
   `GremoVOD Studio QA Token`:
   - имя заголовка `Authorization`,
   - значение `Bearer <машинный токен студии>`.
2. Выбрать его в шести HTTP-узлах: «Создать ревью», «Пакет: критик ТЗ», «Отправить вердикт ТЗ»,
   «Пакет: критик системы», «Отправить вердикт системы», «Итог ревью».
3. Прогнать вручную: вердикты будут `BLOCKED` (критики не подключены) — это ожидаемо.

Токен в workflow не попадает: он живёт только в credential.

## Публичный адрес студии

Постоянный адрес: **`https://studio.grem.win`** — именованный туннель Cloudflare `gremovod-studio`,
id `df5b9eda-c6a8-49c2-ac05-7bf3344a56a1`, DNS-запись `studio.grem.win` уже прописана в туннель.

На ПК:

- конфиг туннеля: `C:\Users\BLOWKA\.cloudflared\config.yml` (ingress: `studio.grem.win` → `http://127.0.0.1:8011`);
- запуск: `cloudflared tunnel run gremovod-studio`;
- чтобы туннель поднимался сам: `cloudflared service install` (затем `cloudflared service start`);
- в студии: `STUDIO_REMOTE_HOSTS=studio.grem.win` — иначе запрос с чужим Host отклоняется (403).

В workflow адрес собирается в одном месте — узел «Собрать запрос ревью», остальные берут `base` оттуда.
Адрес стенда на ПК (`127.0.0.1:8011`) и порт рабочей студии (`8000`) — разные вещи: рабочую студию
на 8000 туннель не трогает.

Если `studio.grem.win` не резолвится — ещё не разошлась делегация NS домена `grem.win`
после регистрации. Это не ошибка контура: туннель и DNS-запись на стороне Cloudflare уже созданы.

## Чего контур ещё не умеет

- **Критики A6/A7/A8 не подключены.** Нужен поддерживаемый способ вызова saved Agents из workflow;
  `messageAnAgent` в n8n помечен `@deprecated: retired`. Пока — честный `BLOCKED`.
- **Медиа-области (`IMAGE`, `VIDEO`, `AUDIO`) всегда `BLOCKED`.** Доверенный источник появится
  вместе с media inspector; сейчас `trusted_sources` для медиа пуст.
- **Workflow ничего не публикует.** Даже `TEXT_PRECHECK_PASSED_AWAITING_OWNER` — это не релиз:
  решение остаётся за владельцем.
- **Платных вызовов в контуре нет.** Цены и бюджет — на стороне студии.
