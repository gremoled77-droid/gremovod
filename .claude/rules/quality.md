# Проверка результата по типу задачи

Контракт качества — в `AGENTS.md`, раздел «Критерии качества разработки». Здесь он
раскладывается на типы задач: что именно нужно проверить, кроме сборки и тестов.

| Тип задачи | Обязательная реальная проверка |
|---|---|
| Логика бэкенда | тест на временной базе + живой запрос к API в запущенном стенде |
| Миграция SQLite | прогон на **копии** схемы, откат, повторный прогон; `quick_check` до и после |
| Денежный контур | сверка оценки, резерва и списания; проверка, что `UNKNOWN` не приводит к повторному submit |
| UI и дизайн | открыть экран в браузере на стенде, а не только собрать бандл |
| API-контракт | запрос к запущенному стенду и проверка формы ответа, а не только типа в коде |
| Медиа и монтаж | воспроизведение файла, длительность и хэш; монтаж собирается вручную в CapCut |
| Скрипты и утилиты | запуск на временных данных + проверка, что реальные данные не задеты |
| Конфигурация агента | тест хука или правила на разрешённой и на запрещённой операции |

## Статус каждой проверки

Ровно один статус на проверку, без исключений:

- `PASS` — проверка выполнена и зелёная;
- `FAIL` — выполнена и красная; приводится первый блок ошибки;
- `BLOCKED` — выполнить нельзя: называется причина и что её снимет;
- `NOT_RUN` — не выполнялась: называется причина.

«Тесты зелёные» без статусов по типам проверок — это не отчёт. Отчёт без
`NOT_RUN`/`BLOCKED` обычно означает, что непроверенное выдано за проверенное.

## Definition of Done

- код работает, а не только компилируется;
- на изменение есть тест, который до правки падал;
- результат проверен по типу задачи из таблицы выше;
- handoff обновлён (три строки: сделано, файлы, следующий шаг);
- риски и то, что осталось непроверенным, названы явно;
- решение по приёмке принимает ревьюер, не автор.

## Чего не делать

- не запускать платные API ради проверки;
- не ставить системные пакеты;
- не писать в `backend/studio.sqlite3` и другие реальные данные владельца;
- не подменять реальную проверку зелёным mock-тестом;
- не объявлять проверку пройденной, если она не выполнялась.
