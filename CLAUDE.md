## Стек и запуск

- Бэкенд: FastAPI + SQLite, `backend/main.py` + модули с `register(app, studio)`. Порт 8000.
- Фронтенд: React 18 + TypeScript + Vite 6, `@xyflow/react` для узлов. Порт 5173 (`frontend/`).
- Windows-first. Запуск: `.\.venv\Scripts\python.exe scripts\start_studio.py` (или `START_WINDOWS.bat`). Если пишет «already running» — заняты порты 8000/5173 старым процессом; остановить его и запустить заново.
- После правок **бэкенда** нужен перезапуск бэкенда. Фронтенд в dev-режиме обновляется сам.
- Здоровье: http://127.0.0.1:8000/api/health
- Порты (решение владельца, 18.10.2026): рабочая студия на 8000/5173 — из корня `C:/AI_Workflow_Studio` (main); запускает и перезапускает её Claude Code, обычным процессом без прав администратора (`Start-Process`, команда как в `start_studio.py`). Codex свой бэкенд на 8000/5173 не запускает — только на отдельных портах (8001/5174) со своим `STUDIO_DATA_DIR`. Если 8000 занят чужим процессом, который нельзя остановить, — сказать владельцу, не обходить. Учти: `ORIGINS` в `backend/security.py` пропускает только 5173/8000, стенду на других портах нужен прокси без заголовка `Origin`.

## Карта кода

Бэкенд (`backend/`): `adapters.py` и `model_catalog.py` — каталог моделей PiAPI, превью/оценка цены/токен подтверждения/бюджет; `external_generation.py` — ручной маршрут через ChatGPT; `activity.py` — общая лента заданий (`/api/activity`, long-poll); `temp_cleanup.py` — избранное, временные файлы на 7 дней, мягкое удаление в `library/.trash` (30 дней), `POST /api/library/{id}/trash`; `remote_access.py` — пароль/куки/allowlist хостов для облака; `economics.py`, `series_economics.py` — расходы и лимиты; `storyboard.py`, `production_*.py` — сцены/кадры/папки постановки; `character_*.py` — герои, голос (ElevenLabs, Fish Audio).

Фронтенд (`frontend/src/`): `App.tsx` — оболочка и режимы (`mode`); `StageNav.tsx` — левая навигация по этапам; `Dock.tsx` — правая панель очереди/бюджета; `HomeScreen.tsx` («Старт»), `CreateScreen.tsx` («Кадры»), `ProductionStoryboard.tsx` («Раскадровка»), `WorkflowPanel.tsx` + `workflowPlan.ts` («Узлы»), `Lightbox.tsx` (просмотр кадров, стрелки/Esc), `GenerationReview.tsx` (оценка цены и подтверждение любого платного запуска), `ActivityContext.tsx`/`useActivity.ts` (лента заданий, опрос 5 с для картинок и 15 с для видео, всплывающие пузырьки в `GenerationWatcher.tsx`).

Стили: `design.css` — токены (тёмная тема, шрифт Onest, акцент #f2b134) и каркас; `home.css`, `create.css`, `ProductionStoryboard.css`, `lightbox.css`, `mobile.css`. Старый `style.css` — для ещё не перерисованных экранов.

## Решения владельца (не переигрывать без вопроса)

- Монтаж вне студии, в CapCut: студия выгружает клипы и звук в порядке кадров.
- Основной формат 16:9, плюс вертикальная версия 9:16 для рилсов (у каждого кадра должна быть вертикальная версия).
- Голос: и ElevenLabs, и Fish Audio. Музыка отдельно.
- Сейчас работает один, но закладывать помощников: у помощника нет прав удаления (удаление = «в корзину владельца»), своя песочница, свои API-ключи, лимиты задаёт владелец в админке.
- Результаты без сердечка и без использования уходят в корзину через 7 дней и хранятся там 30 дней. Файлы, которые используются в кадрах/референсах/узлах, не удаляются.
- Модели, проверенные вживую (`launch_enabled`): seedream-5-pro, seedream-5-lite (Fast), nano-banana-2.1, qwen-image-2.1, gpt-image-2, gpt-image-2.5, minimax-h3 (видео). Не включать модель в запуск, пока её параметры и цена не проверены реальным вызовом (`verified_at`).

## Правила безопасности и денег

- **Ключи API никогда не печатать, не коммитить, не отправлять.** Файлы `*_API_KEY.txt`, `.env*`, базы и медиа в `.gitignore` — не снимать.
- Любой платный запуск идёт через оценку цены и подтверждение (`GenerationReview`, токен подтверждения, лимиты проекта/дня). Не обходить.
- **API генераций заменяемы, провайдеры будут добавляться. PiAPI — тестовый провайдер**, а не единственный возможный. Проверять «эта модель у этого провайдера» через `model_catalog.llm_spec(model, provider)`, а не условием `provider == 'piapi'` в коде: вендор, цена и имя модели у провайдера — данные реестра. Учёт денег (оценка, подтверждение, лимит, журнал расходов) общий для всех провайдеров и не переписывается при добавлении нового. Порядок подключения и правила — `docs/GENERATION_PROVIDERS.md`.
- Тестовые платные вызовы — только по явному разрешению владельца и с малой суммой (раньше разрешал: до $1 за вызов, до $5 всего, низкое/среднее качество). Спрашивать заново в новой сессии.
- Не удалять файлы владельца: мягкое удаление в корзину с журналом `cleanup_journal`.
- Не обходить Cloudflare и не подделывать User-Agent.
