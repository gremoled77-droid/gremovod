# Агент-сборщик монтажа

Решения «что и почему склеивать» — в [gremovod-stage-editing](../gremovod-stage-editing/SKILL.md) и [cinema-editing](../cinema-editing/SKILL.md). Этот скилл — **как собрать и проверить**. Финальный монтаж делает владелец в CapCut; агент готовит черновик и пакет, а не финал.

Основа — опыт агентного монтажа уроков (Исламов, 10.2026): агент на одну единицу работы, правила копятся в файле, рендер не стартует, пока ворота не пройдены, человеку — только короткие вопросы.

## Перед началом

1. Прочитать [MONTAGE_RULES.md](references/MONTAGE_RULES.md) целиком. Это живые правила владельца: они важнее умолчаний ниже.
2. Взять серию: `GET /api/productions/{pid}/series/{sid}/edit-list` (порядок, видео, длительность ffprobe, секторы, склейки, предупреждения) и `GET /api/productions/{pid}/series/{sid}/sound` (реплики, эффекты, `level_db`, `start_s`, `duration_s`, файлы).
3. Номер версии: следующий свободный `vNN` в папке серии `Монтаж/`. Старые версии не трогать.

## Песочница (не нарушать)

- Ничего не удалять и не перезаписывать в исходниках: только чтение клипов/звука, запись в `Монтаж/vNN/`.
- Без платных вызовов (генерация, TTS, апскейл). Нужен добор — записать в «Сомнения».
- Ничего не отправлять наружу и не публиковать. Ключи не читать.
- ffmpeg: `tools/ffmpeg/bin/ffmpeg.exe` рядом с корнем студии (см. `backend/clip_chain.py`) или из PATH.

## Шаги

1. **Ворота «Файлы и порядок»** (см. ниже). Если не прошли — остановиться и выдать отчёт.
2. **Прокси 540p** для каждого клипа (исходник не трогаем):
   `ffmpeg -i in.mp4 -vf "scale=-2:540,fps=24" -c:v libx264 -preset veryfast -crf 26 -c:a aac -b:a 128k -ar 48000 proxy/NN.mp4`
   Одинаковые fps/кодек/частота звука у всех прокси — тогда склейка через `concat` без перекодирования.
3. **Контактный лист стыков**: для каждой пары A→B последний кадр A и первый кадр B рядом
   (`-sseof -0.05 -i A.mp4 -frames:v 1 a.png`, `-i B.mp4 -frames:v 1 b.png`, `hstack`). Посмотреть глазами каждый стык.
4. **Звук**: собрать дорожку реплик по `start_s` кадров + эффекты/атмосфера с `level_db`; измерить (ворота «Звук»).
5. **Черновик**: `concat` прокси + наложение звука → `draft_16x9.mp4`. Затем вертикаль (ворота «9:16»).
6. **SRT** из реплик: время = смещение кадра в монтаже + `start_s` реплики, длительность — по фактическому аудио (ffprobe), а не по оценке. Текст — дословно как в реплике, с написаниями из словаря правил. Числа и составные названия не разрывать между строками.
7. **Пакет для CapCut** в `Монтаж/vNN/capcut/`: `001_с1к1.mp4…` (оригиналы-копии в порядке монтажа), `audio/` (реплики `001_…`, эффекты, музыка), `edit-list.csv`, `sound-list.csv`, `subs.srt`. Редактируемый проект CapCut не обещать (см. TODO).
8. **Отчёт** (`Монтаж/vNN/REPORT.md`) — формат ниже.

## Ворота (без прохождения — нет сдачи)

**Файлы и порядок**
- У каждого кадра выбран видеофайл, файл физически есть, ffprobe читает длительность. Пропуск = стоп.
- Порядок пакета совпадает с `order` из edit-list; число клипов = число строк.
- У каждой реплики есть аудиофайл (`status: file`); реплики-«план» перечислить.

**Стыки клипов** (по контактному листу)
- Скачок позиции/размера героя между последним кадром A и первым B без смысловой причины = «подпрыгивание» → в «Сомнения» (варианты: подрезать начало B, растворение 4–6 кадров, добор с последнего кадра A через `POST /api/library/{asset_id}/last-frame`).
- `sector_cut: прыжок` и `image_cut` с низкой оценкой: оставить, только если это задуманный удар (бит); иначе в «Сомнения».
- Склейка не режет движение посреди фазы и не оставляет «пустое» начало/хвост ИИ-клипа (замирание, морфинг).

**Вертикаль 9:16**
- Кроп по центру по умолчанию; для каждого кадра снять кадр середины в 9:16 и проверить: лицо говорящего и ключевое действие (руль, рычаг КПП, взгляд) в кадре.
- Субтитры в 9:16 — в нижней трети, выше интерфейса рилсов (не ниже ~15% от низа) и не на лице. Если лицо внизу — субтитры поднять или кадр в «Сомнения».
- Если у кадра есть отдельная вертикальная версия — брать её, а не кроп.

**Звук**
- Реплика целиком внутри своего клипа: `start_s + длительность аудио ≤ длительность клипа` (с запасом ≥0,15 с). Иначе обрезка последнего слова = стоп, в «Сомнения» (продлить клип / сдвинуть / перенести хвост реплики на следующий кадр).
- Хвост реплики не обрезан: `silencedetect=n=-40dB:d=0.1` в конце аудиофайла должен находить тишину; нет тишины → файл TTS обрезан.
- Эффекты минимум на 6 дБ тише голоса (ориентир 15–20 дБ), не чаще одного акцента в 2 с; музыка под речью ≈ на 15–20 дБ ниже.
- Итог черновика: `loudnorm=print_format=json` — ориентир −14 LUFS интегрально, пик не выше −1 dBTP. Отклонение больше 2 LU — отметить.
- Шумоподавление/«улучшение» — только чистому голосу до сборки, никогда готовому миксу (вырежет эффекты).
- Проверка по таймингам TTS: если у реплики есть выравнивание по символам (ElevenLabs with-timestamps) — сверить, что последний символ укладывается в клип. Сейчас студия его не сохраняет: проверять по длительности файла и silencedetect, отметить в отчёте «без выравнивания».

## Отчёт

```
# Серия N, черновик vNN — 2026-10-18
Итог: 24 кадра, 2:41, 23 склейки (8,6/мин). Ворота: файлы ✓, стыки 2 вопроса, 9:16 1 вопрос, звук ✓.
Файлы: draft_16x9.mp4, draft_9x16.mp4, capcut/

## Сомнения (ответ одним словом: «1. растворение», «2. оставить»)
1. 00:42 стык 3.2→3.3: Грэм «подпрыгивает» вправо. растворение / подрезать / добор?
2. 01:15 к. 4.1 в 9:16 рука на КПП вне кадра. сдвинуть кроп влево / оставить?

## Сделано без вопросов
- …
```

Владельцу — простыми словами и только то, где нужно его решение. Технические детали — ниже, в «Журнале».

## После ответа владельца

- Ответы применить, собрать `vNN+1`, в отчёте перечислить, что изменено.
- Любое замечание, которое касается не одного кадра, а вкуса/правила («эффекты тише», «не резать последнее слово»), — дописать в [MONTAGE_RULES.md](references/MONTAGE_RULES.md) с датой и примером. Так скилл умнеет от каждой правки.
