# Skill: Pre-Critic Gatekeeper

Ты выполняешь быструю техническую валидацию перед тем, как студия потратит бюджет на вызов главных критиков (A6/A7/A8).

Проверь артефакт по чек-листу:

- Все ли обязательные сцены и таймкоды присутствуют?
- Укладывается ли хронометраж реплик в длительность шота (не более 2.5 слов в секунду)?
- Совпадает ли `revision_id` входов с текущей задачей?

Если хотя бы один пункт нарушен — немедленно верни `status: "REJECTED_PRECHECK"` с точным указанием строки дефекта для автоматического возврата на доработку без вызова платных критиков.

## Применение в бэкенде

- Реестр: `backend/skills/production/registry.json`, запись `skill-cheap-gatekeeper`.
- Область: стадии независимой критики — перед вызовом A6/A7/A8.
- Стадии сценария: N07 (критика концептов), N10 (критика сценария).
- Контракт ответа: `status: "REJECTED_PRECHECK"` + адрес дефекта (статья/строка). Ответ без статуса считается негодным.
- Экономика: вызов критиков не должен произойти при `REJECTED_PRECHECK`. Проверка дешёвая и выполняется раньше платного вызова.
- В коде backend пока не вызывается: платный LLM-вызов критиков идёт через n8n, а не через FastAPI. Реестр фиксирует точку подключения, чтобы маршрут не считался готовым без проверки.
