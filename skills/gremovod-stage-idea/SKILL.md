# 1. Идея и сценарий

Для работы со страницей «Идея» (`studio`). [Карта восьми страниц и границы подключения](../../docs/STAGE_SKILLS_2026-10-16.md).

**Вход:** замысел владельца, формат, текущая версия сценария, доступный канон мира и героев. При новом замысле достаточно имеющихся сведений; недостающее обозначить. При импорте сохранить авторский текст, анализ выдать отдельно.

## Решения

1. Сформулировать обещание истории: кто чего хочет, что мешает и почему зрителю это интересно. Выбрать точку зрения и жанр; не подменять сюжет перечнем киноэффектов.
2. По [cinema-narrative-genre](../cinema-narrative-genre/SKILL.md) выбрать события и связи между ними. По [драматургии персонажа](../gremovod-character-dramaturgy/SKILL.md) проверить желание, альтернативы и цену выбора. Набросать результат истории до окончательной шлифовки реплик.
3. Для нового выпуска записать управляющую идею («ценность + причина») и проверить побуждающее событие: нарушает ли оно равновесие, рождает ли желание и вопрос «чем кончится». Придумать финал до шлифовки пути к нему: кризис как настоящая дилемма, климакс ясным действием без объяснений ([принципы Story](../cinema-narrative-genre/references/mckee-story-principles.md)). Для ролика достаточно короткой формулы, а не разметки по актам.
4. Сравнить полезные альтернативы развития, выбрать совместимую с героем и миром. Для короткой истории не требовать заданных долей актов, числа сцен или обязательной побочной линии.
5. Написать действие и диалог. Каждая реплика исходит из ситуации и попытки героя чего-то добиться; слушатель может ответить молчанием, жестом или поступком. Не объяснять словами то, что уже понятно из изображения. Приёмы диалога как действия и характерной речи — в [gremovod-dialogue-subtext](../gremovod-dialogue-subtext/SKILL.md) (раздел «Диалог как действие», по книге Dialogue Макки).
6. Проверить историю кратким пересказом и чтением вслух с паузами. Измеренный хронометраж отделить от оценки по тексту. Для комедии проверить подготовку, неожиданное раскрытие и реакцию; смешной исход нельзя объявить доказанным по одному текстовому анализу.

По [Снайдеру](../gremovod-script-rewrite/references/snyder-save-the-cat.md#2-проверка-идеи-гл-1) проверить, не «слишком проста», «слишком сложна» или «слишком скрытна» идея, и попробовать шаблон «на пороге … но когда … должен усвоить …»; это проверка, а не обязательная формула.

**Выход:** логлайн, краткий план событий, сценарий по сценам с репликами, версия и список новых предложений к канону. Для данных доски применять [gremovod-screenplay](../gremovod-screenplay/SKILL.md); формат, стабильные ключи и реальные ID сохранять.

**Готовность к передаче:** ясны желание, противодействие, изменение и результат; реплики принадлежат конкретным героям; есть различие между сценой, смысловым битом и монтажным планом. Если у сцены только информационная функция, предложить способ встроить её в действие, сохранив исходную версию.

**Возврат:** невозможный для мира ход → «Мир»; неясный поступок → профиль персонажа; непонятный финал → структура событий. Красивые реплики не исправляют причинность автоматически.

Материалы сценария сохранять локально в выбранном проекте или черновике, вне Git исходников приложения. Этот навык не записывает данные через API и не запускает генерации сам по себе.

## Для комедийного мультсериала

Для нескольких выпусков или проверки пилота применять [развитие сериала](../gremovod-series-development/SKILL.md): отдельная задача выпуска и потенциал продолжения. Для анализа существующего текста — [адресную редактуру](../gremovod-script-rewrite/SKILL.md); для непрямых реплик и умолчаний — [подтекст диалога](../gremovod-dialogue-subtext/SKILL.md). Не смешивать анализ с разрешением переписать исходник. Внешний результат сцены должен быть понятен, а скрытый мотив — иметь наблюдаемую опору.

По [gremovod-character-comedy](../gremovod-character-comedy/SKILL.md) проверить, что юмор растёт из желания, особого взгляда и попытки героя, а партнёр действует ради собственной цели. Реплику оценивать как попытку получить ответ, а не только как остроту. Зафиксировать, чего ждёт зритель и какой результат меняет ожидание; не объявлять гипотезу интереса измеренным удержанием. Для ясности раскрытия и реакции подключить [gremovod-comedy-staging](../gremovod-comedy-staging/SKILL.md). Применять к конкретной проблеме, сохраняя удачные сцены и авторскую версию.
