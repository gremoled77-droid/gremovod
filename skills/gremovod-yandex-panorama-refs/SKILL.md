# Референсы места из Яндекс.Панорам

Задача: из адреса или точки получить 4 картинки «вокруг точки» для будущей перерисовки в мультяшный стиль и положить их в `projects/<проект>/Real Reference/<имя места>/`. Это личные референсы владельца: не публиковать, в генерацию не отправлять, пока он сам не решит.

Скрипт: `~/.claude/skills/gremovod-yandex-panorama-refs/grab_panorama.py` (копия в репозитории `skills/gremovod-yandex-panorama-refs/`). Нужны Pillow, numpy, opencv (в `.venv` студии они есть): `C:/AI_Workflow_Studio/.venv/Scripts/python.exe -X utf8 <скрипт> ...`.

## Правила (не нарушать)
- Работать только во **встроенном браузере** (`mcp__Claude_Browser__*`). Яндекс отдаёт headless-браузеру страницу «limited»: **не обходить, не подделывать User-Agent**. Капча или блок: остановиться и сказать владельцу.
- Картинки сохраняются снимком экрана: скрипт берёт пиксели с экрана, где панорама уже открыта. Поэтому окно браузера должно быть **сверху и целиком видно**; перед каждым снимком `tabs_select`, после снимка проверить результат глазами (поверх может всплыть чужое окно, например Total Commander). Такие кадры выбросить и снять заново.
- Снимки всего экрана (`--thumb`, временные) удалять сразу после использования: на них личный рабочий стол.
- Права: панорамы защищены. Только скрытая папка `Real Reference`, без публикации. Надписи на самих домах не убираются (это при перерисовке).
- Платных вызовов нет. Файлы владельца не перезаписывать: если папка есть, добавить суффикс `_2`.

## Порядок

1. **Точка.** Владелец дал ссылку на панораму: взять `panorama[point]=долгота,широта` из адреса. Дал адрес: открыть `https://yandex.by/maps/157/minsk/search/<адрес>/`, подождать 2 секунды, прочитать координаты из `ll=` в адресе страницы (`location.href` через `javascript_tool`). Если улица, а не двор, спросить, какой именно двор (сдвинуться на соседние точки, где нужна булыжная/дворовая картинка).
2. **Панорама.** Открыть (подставить координаты):
   `https://yandex.by/maps/157/minsk/?l=stv%2Csta&ll=<lon>%2C<lat>&panorama%5Bdirection%5D=<AZ>%2C-5&panorama%5Bfull%5D=true&panorama%5Bpoint%5D=<lon>%2C<lat>&panorama%5Bspan%5D=95.657841%2C60.000000&z=17`
   Яндекс «притянет» точку к ближайшей панораме: после первой загрузки взять `panorama[point]` из итогового адреса и использовать его для всех четырёх сторон (иначе стороны будут сняты из разных мест). Азимут `AZ`: 0, 90, 180, 270 (север, восток, юг, запад); наклон -5.
3. **Калибровка (один раз, при новой раскладке окон).** `grab_panorama.py --thumb C:/Temp/desk.png`, посмотреть картинку (`Read`), найти прямоугольник самой панорамы без карты внизу и панели вкладок; координаты умножить на коэффициент из вывода; запомнить: `--box X0 Y0 X1 Y1 --save-box`. Для окна владельца (экран 3840x1600, браузер отдельным окном) рамка уже в скрипте: 1459 225 3178 1123.
4. **По одному кадру на сторону:** `navigate` на адрес с нужным `AZ` → `computer wait 3` → `tabs_select` → `grab_panorama.py --out C:/Temp/pano/az<AZ>.png`.
5. **Проверка.** Склеить: `--sheet az000.png az090.png az180.png az270.png --out sheet.png`, посмотреть. Что-то осталось (розовые, синие, зелёные кружки отметок с подписью, звёздочки, посторонний край): повторить снимок с `--mask x,y,w,h` (координаты в картинке; можно несколько `--mask`). Оранжевые кружки закрашиваются сами.
6. **Сохранить.** `projects/GremoVOD/Real Reference/<имя>/`, имя по адресу: «Двор на Немиге (Герцена)», «Комаровка (Игнатенко 2)» и т.п. Файлы `север_0.png`, `восток_90.png`, `юг_180.png`, `запад_270.png` и `ОПИСАНИЕ.txt` (источник, координаты, направления, что закрашено, пометка «не публиковать»). Папка `projects/` в `.gitignore`, в git ничего не попадает.
7. **Убрать временное:** `C:/Temp/pano`, `C:/Temp/desk.png`.
8. Показать владельцу сетку из четырёх картинок и короткую заметку: что на каждой, какие бренды видны, какую сторону я бы взял.

## Известные ограничения
- Рамка панорамы привязана к раскладке окон владельца; при другом размере экрана или окна калибровка заново.
- Положение отметок организаций меняется от кадра к кадру: автоматическая закраска ловит только оранжевые.
- Это снимок экрана, качество равно размеру окна (около 1600x900). Для больших картинок увеличить окно браузера.
