# 3. Раскадровка

Для страницы `storyboard`. [Карта страниц](../../docs/STAGE_SKILLS_2026-10-16.md).

**Вход:** одна версия сценария, сущности и референсы мира, существующая доска. Структуру и связывание читать в [gremovod-screenplay](../gremovod-screenplay/SKILL.md).

## Решения

1. Выделить смысловые изменения в сцене: действие героя, ответ партнёра, новый способ добиться цели. Бит не равен одному кадру и не равен каждой произнесённой реплике.
2. Выбрать, что зритель должен знать и чего пока не знать. По [cinema-mise-en-scene](../cinema-mise-en-scene/SKILL.md) поставить участников, предметы и читаемые контакты. Использовать материал Уильямса из этого навыка для ключевых состояний.
3. По [cinema-camera-work](../cinema-camera-work/SKILL.md) выбрать для каждого плана функцию, крупность, точку, направление взгляда и движение камеры. Лицо для малой реакции, более широкий план для пространственного действия — варианты по задаче, а не обязательная схема. Смена говорящего не требует автоматической склейки.
4. По [cinema-editing](../cinema-editing/SKILL.md) проверить соседние планы: ось, взгляды, направление, фазу действия и перенос внимания. Оставить место для реакции слушателя и для звука поверх неё. Ориентация нужна зрителю; общий план не обязан открывать сцену.
5. По [cinema-visual-structure](../cinema-visual-structure/SKILL.md) выбрать выразительные изменения, не меняя все компоненты разом без причины. Проверить черновую последовательность с голосовыми набросками и паузами до дорогих клипов.

**Выход:** карточки кадров в существующей иерархии, схема сцены, заметки для стыков и черновой тайминг. Для кадра: функция; видимые герои; ракурс; важное действие/реакция; нужный предмет; свет; начальное и конечное состояние; ссылка на реплику и референсы. Дополнительные заметки не превращать в обязательные поля JSON без отдельной реализации.

**Готовность к передаче:** последовательность понятна без финальной красоты; событие и ключевая реакция не потеряны; герой не телепортируется между местами; у 16:9 и 9:16 предусмотрена читаемая композиция.

**Возврат:** непонятна причинность → «Идея»; неверна география → «Мир»; ошибочна одна крупность → исправить план, сохранив его ключ и связанные версии. Эта инструкция сама не создаёт доску через API.

Для покрытия сцены и сложного движения использовать [практику The Art of Camera Movement](../cinema-camera-work/references/art-of-camera-movement.md): отдельно вести монтажный порядок и уникальные установки, отметить A/B камеры на схеме сверху, проверить ось, перекрытия, момент раскрытия и темп реакции. Сложный приём должен иметь смысл и простой запасной вариант; раскадровка не требует нового ракурса для каждой реплики.

По [Брауну](../cinema-camera-work/references/brown-visual-grammar.md#7-набор-кадров-сцены-с-5871) для набора кадров сцены проверить, есть ли заявочный план с частью истории, мастер, реакция слушающего, нужные вставки (информационные, акцентные, атмосферные), соединительный кадр там, где одиночные планы плохо связаны, и перебивка как запас для монтажа. Для сцен с движением записать направление героя на экране и ось действия. Это проверочный перечень, а не требование снимать всё в каждой сцене.

## Подготовка производства

Применять [порядок подготовки по курсу](references/preproduction-camera-course.md): разбор видимых событий → схема сверху → уникальные установки → монтажная последовательность → очередь производства по зависимостям. Отдельно сохранить состояния реквизита и необходимые реакции. Одна установка может обслуживать несколько кадров, но их ключи и состояния остаются раздельными. До дорогого движения проверить покрытие черновой сборкой; для сложного приёма подготовить простой вариант. Это постановочные заметки, не новые обязательные поля и не автоматический запуск заданий.

## Комический фокус

По [gremovod-comedy-staging](../gremovod-comedy-staging/SKILL.md) отметить, что знает зритель и каждый герой, когда показывается важная деталь и чья реакция несёт событие. Не закреплять за одним героем все смешные поступки, а за другим все разумные ответы: фокус может меняться по битам. Выбрать совместный или ответный план по моменту понимания; не делать механическую склейку после каждой шутки.
