# Стартовое меню → GPT-ветка → готовый промпт

Реализована первая версия маршрута по запросу пользователя: сначала выбрать необходимые параметры, затем передать их как базу в существующий отдельный чат, где GPT пишет правильный промпт. Выбор карточек и подготовка промпта не запускают медиа.

## Меню

Стартовые панели появились в фото, фото-сцене, Video Lab и видео-сцене. У фото есть быстрые входы в крупность/ракурс, свет и салон авто. У видео — вход в 19 движений камеры. Подробные настройки разворачиваются по запросу, поэтому начальная панель остаётся компактной.

К существующим каталогам добавлены 37 авторских вариантов в 9 группах:

| Группа | Варианты |
|---|---|
| Визуальный стиль | Авторская 3D-анимация, кинематографичный реализм, объёмная иллюстрация, графичная анимация |
| Жанр | Комедия, драма, наблюдение, нуар, масштаб |
| Камера | Современная цифровая, киноплёнка 35 мм, плёнка 8 мм, DV |
| Объектив | Чистая резкость, анаморфотная, винтажная анаморфотная, тёплая винтажная, ореолы светов |
| Угол обзора | Умеренно широкий, естественный, портретный |
| Фокус | Главный герой, оба собеседника, вся сцена, выбранная деталь |
| Палитра | Естественная, янтарь и синий, приглушённая, тёплая, прохладная |
| Настроение | Спокойное, доверительное, напряжённое, ироничное |
| Фактура и детализация | Чистая проработка, мягкая отделка, материальная фактура |

В каждой группе можно оставить «По заданию и референсу». Отсутствие выбора не подменяется произвольным пресетом. Полное заполнение не требуется.

Карточки содержат русское описание эффекта и собственные схематические миниатюры. Миниатюры не являются сгенерированными тестами оптики и не доказывают визуальную точность модели. Текст инструкций описывает наблюдаемые свойства, а не произвольные «8K / masterpiece». Канон лица, одежды и салона сохраняется; художественный эффект не устанавливает техническое разрешение или скрытое качество API.

## Передача в отдельную ветку

Основная кнопка: **«Подготовить промпт в GPT-ветке»**. Она сначала сохраняет проект, затем ставит существующее задание `operation=prompt` в очередь чата [«ChatGPT — промпты и изображения»](codex://threads/01a13e25-939c-7b73-9c0a-669abc8aa6a7).

Задание содержит исходное описание, роли референсов, выбранную целевую модель, композицию/свет или движение и структурированный `prompt_base` с ID, названиями, описаниями и содержательными инструкциями. GPT должен согласовать их и написать связный промпт, а не вернуть механическую склейку ярлыков. Явные композиция, рассадка, география света и канон имеют приоритет над побочными эффектами стилизации.

В задании явно закреплены `execution.prompt_only=true`, запрет imagegen/платного API и остановка после `prompt-ready`. При завершении промпт возвращается в студию, его текст раскрыт для проверки. Сервер переводит задание в `completed`, а не `generating`; загрузить в него незапрошенное изображение нельзя. Существующий комбинированный запуск «промпт + фото» сохранён внутри отдельного свёрнутого дополнительного действия.

**Обработчик должен быть активен.** Поддерживаемого автоматического пробуждения сервером нет. Если чат не слушает очередь, интерфейс показывает ожидание и ссылку на ветку с инструкцией «Продолжай очередь студии». Этот шаг не добавлял скрытый платный резерв или автоматическое внешнее сообщение.

## Данные и актуальность

Один файл `backend/prompt_setup_catalogue.json` служит источником параметров для Python и TypeScript. Валидация отклоняет неизвестные группы и ID. Собственные заметки по сцене остаются обычным пользовательским заданием.

Реальная реализация использует необязательное `composition.setup` для фото и `camera.setup` для видео. Это уточняет первоначальное предложение отдельного `state.optics`: вложение в существующие контракты позволяет включить базу в уже работающие снимки и подписи промптов без второй параллельной системы актуальности. Параметры фото и видео сохраняются независимо; видео с исходным изображением по умолчанию сохраняет его дизайн.

Смена выбранной линзы, палитры или другой настройки меняет подпись промпта. Запоздалый ответ остаётся связан с исходными параметрами; новые настройки проекта не затираются. Пустой `setup` не меняет старые подписи. Порядок ключей нормализован одинаково в Python и TypeScript.

Это режиссёрская база для GPT, а не прямые параметры произвольного API. Соотношение сторон, разрешение и длительность по-прежнему задаются в поддерживаемых технических настройках выбранной модели. Рисунок анаморфотной оптики не меняет аспект, плёнка не переносит действие в другую эпоху, палитра не перемещает источники света.

## Проверка

77 серверных тестов, 7 проверок состояния Node и сборка TypeScript/Vite прошли. Новые проверки покрывают базу без выбранного движения, валидацию, сохранение снимка настроек для фото/видео, завершение prompt-only без изображения, отказ принимать медиа для такого задания, совместимость старых подписей и равенство подписей Python/TypeScript.

В браузере проверены выбор нескольких параметров, сводка базы, раскрытие карточек и наличие основной кнопки передачи в GPT в настоящем приложении. Рабочий проект для проверки не менялся, производственные задания не запускались. Тестовая очередь работает с временной БД и запрещёнными внешними вызовами.

Новый каталог подтверждён на работающем backend: `/api/frame-presets` отдаёт `version: 2026-10-15-start-menu` и `capabilities.prompt_setup=true`. Старый сервер показывает уведомление и блокирует неподдерживаемые новые параметры.
