## Что сделано в этой ветке

### 1. Платный вызов — только по резерву в журнале расходов (главное)

Проблема: `/api/chat`, `/api/compose` и `/api/agents/run` обращались к
платному провайдеру без оценки, без подтверждения и без записи в журнал
расходов. Единственный барьер — стоп-лист из трёх путей в middleware
(`security.py`), то есть новая платная точка открывала оплату по умолчанию.

Решение: граница перенесена в единственную точку выхода к провайдеру.

- `backend/main.py::require_spend_reservation` — платный POST проверяет наличие
  резерва: `llm_calls` (LLM) или `jobs` + `generation_approvals` (генерация).
- `backend/main.py::request_piapi` и `backend/kie.py::request` — POST без
  резерва отклоняется (403) до обращения к провайдеру. GET (статус задачи)
  остаётся бесплатным.
- `backend/security.py::spend_reserved` — сама проверка резерва.
- `/api/chat` закрыт (410) и отправляет на `/api/llm/chat`.
- `agent_completion`: провайдер только PiAPI, прямой вызов OpenAI убран —
  у него не было ни оценки, ни лимита, ни учёта.
- `security.py`: из стоп-листа убран `/api/chat`; `/api/compose` и
  `/api/agents/run` остаются заморожены (503) — это решение владельца.

Новый маршрут теперь не может заплатить, даже если его забудут внести в
стоп-лист.

### 2. Один реестр LLM вместо трёх копий

- `backend/model_catalog.py::LLM_MODELS` — источник истины: подпись, цена,
  провайдер, область (`workflow` / `idea` / `task`), имя модели у провайдера.
- `llm_guard.PRICES`, `MINIMAX_PRICES`, `MINIMAX_PROVIDER_MODELS` и
  `ALLOWED_CHAT` выводятся из него.
- `frontend/src/llmPricing.ts` — копия для синхронного рендера; соответствие
  реестру проверяет `backend/test_llm_registry.py` (падёт при расхождении).
- Оценка во фронтенде приведена к формуле backend (2 символа на токен), чтобы
  предпросмотр не был дешевле принудительной оценки.

ровно вдвое. Оценка в backend завышена вдвое — это безопасно для бюджета, но
фактическое списание считается по usage, и в журнале расходов суммы будут
завышены. Решение (какая цена верна: M Plan или API) — за владельцем.
