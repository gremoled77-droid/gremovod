# GremoVOD — ручной цикл GPT/Aider → Git → Argon

Связанные задачи: #21

## Принцип

- **GPT через Aider** — исполнитель и автор кода.
- **Git** — единственный источник изменений и ревизий, отчётность через Draft PR.
- **Gemini 4 Argon (KIE)** — независимый текстовый ревьюер diff; не получает прав на запись.
- **Пользователь** — утверждает платные API-запросы и внесение исправлений.

## Что НЕ активировать сейчас

Не менять рабочий GPT-6 Sol / KIE Proxy v2 (порт 8767).
Не подключать Argon к `--auto-test` или платным GitHub Actions.
Не включать auto-commits, caching/keepalive и `--edit-format diff` без теста конкретной модели.
Не запускать повторные AI-запросы при HTTP 429, 5xx и тайм-аутах.
Не использовать `git clean`, `reset --hard`, `add -A` в `C:\AI_Workflow_Studio`.

## Пошаговая схема

1. Убедиться, что локальный `git remote -v` соответствует `gremoled77-droid/gremovod`, затем использовать отдельный worktree.
2. В Aider передавать ограниченную задачу. Сначала `ask`, после утверждения — редактирование в тестовой ветке.
3. Выполнить **бесплатные** детерминированные тесты; не использовать реальные генерации.
4. Сделать контролируемый коммит. Выбрать **явные** базовую и конечную ревизии для `git diff --unified=3 <base> <head>`.
5. До KIE — проверить файлы/размер/бинарные изменения/возможные секреты и SHA-256; сохранить офлайн-отчёт за пределами репозитория.
6. Только по явному согласию отправить **один** текстовый запрос Argon к `https://api.kie.ai/gemini-4-argon-openai/v1/chat/completions`.
7. Проверить замечания Argon вручную; отдельно отличать ошибки API от ошибок кода. Исправления поручать GPT только после подтверждения.
8. Размещать *санитизированную* сводку в разделе **Conversation** чернового PR. Изменения кода смотреть в **Files changed**, бесплатные тесты — в **Checks**.

## Критерии MVP

- По умолчанию офлайн и без расходования кредитов.
- Argon не может менять файлы Git и не вызывается автоматически.
- Секреты и бинарные файлы не отправляются; весь состав запроса пользователь проверяет.
- Сетевые сбои не превращаются в запрос GPT на «исправление кода».
- В отчёте сохраняются base/head, digest, статус и решение пользователя.
- В репозитории main ничего не меняется без ревью и merge.

## Ограничения

У GitHub и локального Windows-репозитория разное состояние, пока не выполнены синхронизация и проверка `remote`.
Незакоммиченные файлы и `??` не входят в сравнение двух коммитов.
GPT-6.1 Sol через существующий прокси пока не проходил LIVE-тест.
Работа Argon в chat-only API не заменяет настоящие тесты; PASS — не гарантия отсутствия ошибок.
