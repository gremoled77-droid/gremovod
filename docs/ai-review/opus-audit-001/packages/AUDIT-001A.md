```powershell
$root = "C:\Users\BLOWKA\Documents\Minimax\gremovod\docs\ai-review\opus-audit-001"
```

Затем: system prompt → в поле `system`, остальные пять — в поле `user` одним
сообщением, в указанном порядке, с заголовками-разделителями вида
`=== FILE: P0_EVIDENCE.md ===`.

> Разделы 1–5 из `OPUS_FIRST_REQUEST.md` содержат ссылки на материалы по именам.
> Это сделано намеренно: так владелец может править запрос, не трогая доказательства.

## 4. Критерии приёмки ответа

Ответ A считается пригодным, если по **каждому** из B-1…B-8:

- [ ] стоит вердикт из фиксированного списка (IMPLEMENTED / PARTIAL / SPEC-ONLY /
      MOCK / MISSING / RISK) + одно предложение-обоснование;
- [ ] приведены `путь:строка` (а не «в модуле бюджета»);
- [ ] код процитирован, а не пересказан; если кода нет — сказано «кода нет»;
- [ ] есть блок «что осталось открытым»;
- [ ] рекомендация начинается с «Исправить:» или «Проверить:».

И на уровне пакета:

- [ ] дан **топ-5 рисков** по ожидаемой стоимости;
- [ ] дан **явный список недостающих данных** (а не молчаливое допущение);
- [ ] Opus **не** утверждает, что платные пути проверены — они не проверялись
      (см. `TEST_RESULTS.md` §4). Если утверждает — это дефект чтения, зафиксировать;
- [ ] Opus **не** путает `main` и PR #29. Если выводы про P0 поданы как свойство
      `main` — это дефект чтения, зафиксировать: P0 в `main` отсутствует.
- [ ] Ответ **самостоятелен**: предмет назван заново (файл, узел, PR, ревизия), нет
      отсылок «выше» / «как отмечал ранее». Правило из system prompt v1.1.

## 7. Проверка payload на секреты (обязательно)

```powershell
$payload = Get-Content $out -Raw
# Любое совпадение — повод не отправлять и разобраться вручную.
$patterns = @(
  'sk-[A-Za-z0-9]{16,}',
  'Bearer\s+[A-Za-z0-9_\-]{20,}',
  'AKIA[0-9A-Z]{16}',
  'gh[pousr]_[A-Za-z0-9]{20,}',
  'KIE_API_KEY\s*=\s*["''][^"'']{8,}'
)
foreach ($p in $patterns) {
  if ($payload -match $p) { Write-Output "FOUND: $p" }
}
```

Стандарт проекта: `VALIDATION.json` → `common_token_pattern_scan: "no matches; not
an exhaustive secret audit"`. Пакет аудита должен выдерживать ту же планку.
