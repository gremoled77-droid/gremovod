# OPUS_FIRST_REQUEST — текст первого сообщения (AUDIT-001A)

Это **канонический текст первого запроса**. Он ставится в system prompt по
`OPUS_SYSTEM_PROMPT.md` и отправляется вместе с материалами из
`packages/AUDIT-001A.md`.

Файл существует отдельно от `packages/AUDIT-001A.md`, потому что запрос — это
переиспользуемый артефакт: тот же текст уходит и в AUDIT-001B, и в AUDIT-001C с
заменой только блока «Вопросы» и блока «Материалы».

## Проверка после ответа

1. В ответе `usage.input_tokens` / `usage.output_tokens` — записать в
   `responses/AUDIT-001A.response.json`.
2. Убедиться, что `model` = `claude-opus-5-5`, а не другая модель KIE по умолчанию.
3. Сверить каждый вердикт Opus с `P0_EVIDENCE.md`: если Opus утверждает, что
   «файла нет», а файл в материале есть — это ошибка чтения, зафиксировать.
4. **Не отправлять AUDIT-001B автоматически.** Сначала разобрать ответ A.
