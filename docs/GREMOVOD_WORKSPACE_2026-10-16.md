## Код обслуживания

`scripts/promote_production_workspace.py` по умолчанию только показывает план. `--apply` сначала делает резервную копию; `--archive-source` скрывает старый тест. Не запускать этот скрипт автоматически при старте студии. `backend/production_workspace.py` отказывает при конфликте общих персонажей, другой связи назначения, изменившемся источнике или незавершённых заданиях старого проекта; перенос файлов выполняется добавлением копий, БД меняется в транзакции. Неполная копия не публикуется; при сбое БД исходные файлы остаются доступны.

Следующий пункт: последовательно привести оставшиеся страницы к общему дизайну и сценарию работы, начиная с «Мир»/редактора персонажей. Пустые «Новые персонажи» не удалялись автоматически.
