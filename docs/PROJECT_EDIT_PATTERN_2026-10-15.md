# Название проекта: сохранить → просмотр → редактировать

Реализовано в `frontend/src/ProjectHeader.tsx`, подключено к существующему сохранению в `App.tsx`.

- Новый проект: поле названия и кнопка **Сохранить**.
- После подтверждённого сервером сохранения: обычное название, справа иконка карандаша. Кнопка сохранения скрыта, если новых правок нет.
- Карандаш: открывает поле названия, **Сохранить** и **Отмена**.
- Отмена возвращает сохранённое название, сохраняя другие локальные правки. Enter сохраняет, Escape отменяет переименование.
- Изменение остальных данных проекта показывает индикатор несохранённых изменений и возвращает кнопку сохранения.
- Возврат всех полей к сохранённым значениям снова скрывает кнопку.
- Пустое название не отправляется. При ошибке сохранения форма остаётся доступной; название не переводится в режим просмотра как будто запрос прошёл.

Существующая проверка версии и объединение изменений сохранены. Это явное сохранение; автоматическое сохранение и восстановление последнего открытого проекта остаются отдельными задачами.

Компонент управляет представлением, обработчики сохранения передаются снаружи. Этот подход можно дальше применять к названиям сцен, персонажей и локаций, сохраняя их собственные API и правила версий. В текущем изменении режим добавлен только к названию проекта студии.

Проверка: TypeScript/Vite build, 3 теста объединения. В браузере на GremoVOD проверены загрузка сохранённого проекта, вход по карандашу, отмена переименования, сохранение без смены названия, появление кнопки при изменении задания и исчезновение после возврата исходного текста. Тестовое переименование и текст задания не сохранялись. Платных генераций не было.
