## 2. Как устроена интеграция

```
n8n Cloud                     FastAPI (локальная студия)
──────────                    ─────────────────────────
WF_00 P0                      /api/scenario/producer
  → scenario_params      ──▶    машинный токен + зона проекта
WF_01 01 параметры                только MOCK: 0 $, сети провайдера нет
  → POST /api/scenario/producer   логика этапа, состояние проекта,
  → 03 перевод ответа             модельный адаптер, бюджет
```

- **n8n** инициирует обработку, передаёт параметры и получает результат — больше ничего.
- **FastAPI** держит всю логику этапа (`backend/producer_stage.py`), состояние проекта, модельный адаптер и учёт бюджета.
- Внешний контур **не может выбрать провайдера**: в модели запроса нет таких полей, лишние поля запрещены (`extra='forbid'`).
- Платный запуск сценарного этапа выполняется в студии владельцем: там оценка, подпись и резерв расходов.

### Проблема «n8n Cloud не видит 127.0.0.1:8000»

Решение — уже работающий в этом инстансе мост: публичный адрес студии **`https://studio.grem.win`** (Cloudflare Tunnel, `~/.cloudflared/config.yml` → `studio.grem.win → http://127.0.0.1:8011`). Тот же приём использует существующий черновик «GremoVOD — приёмка через студию» и PROBE-workflow: HTTP Request node с `genericCredentialType` / `httpHeaderAuth`.

Но туннель — только транспорт. Доступ к студии закрыт тремя независимыми замками, и все они проверяются на стороне FastAPI:

1. `remote_access`: удалённый Host разрешён только при `STUDIO_REMOTE_HOSTS` + `STUDIO_ACCESS_PASSWORD` (иначе 403 «Недопустимый Host»).
2. `service_auth`: машинный токен открывает только разрешённые префиксы (`/api/qa/`, `/api/scenario/`), всё остальное API остаётся за браузерной сессией.
3. Сам эндпоинт: токен должен иметь зону проекта, а контур должен быть включён флагом.

## 5. Что требуется от владельца (до первого прогона)

1. **Перезапустить студию из ветки** `minimax/n8n-scenario-dispatch-20261020` — эндпоинта нет в работающей копии.
2. **Выдать машинный токен с зоной проекта:**
   `STUDIO_SERVICE_TOKENS=<токен>:<project_id>` (зона `*` — все проекты, `id1,id2` — перечень).
3. **Включить сценарный контур:** `STUDIO_SCENARIO_ENABLED=1`.
4. **Разрешить удалённый доступ:** `STUDIO_REMOTE_HOSTS=studio.grem.win` и `STUDIO_ACCESS_PASSWORD` (≥ 12 символов). Это и есть «согласование безопасного HTTPS-доступа»: без этих переменных удалённый вызов получает 403, а не результат.
5. **Проверить кред в n8n:** у узла `02` стоит «Header Auth account» (`DXufsqj3qO0pCfyu`). В нём должно быть `Authorization: Bearer <токен из п.2>`. Если там другой секрет — создать отдельный кред и переключить узел.
6. **Прогнать вручную** `WF_00_Core_Infra` (ручной запуск) и убедиться, что `scenario_stage.provenance = 'STUDIO_PRODUCER_MOCK'`, `paid_calls = 0`, `cost_usd = 0`, а финальный статус прежний — `MOCK_PIPELINE_COMPLETE_NO_REAL_APPROVAL`.

**Мелочь в редакторе n8n:** инструмент сохранил `sendBody` строкой `"true"` вместо булева. В интерфейсе тумблер «Send Body» будет включён, а сохранение узла вручную нормализует тип.
