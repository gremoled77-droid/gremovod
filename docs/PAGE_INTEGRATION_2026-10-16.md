# Связи страниц и размеры «Кадров» — 16.10.2026

Выполнена очередь из шести пунктов: общий контекст, переходы, доставка результата, очередь, восстановление и проверки. Текущий дизайн Claude Code сохранён. Это исправление интеграции существующих экранов, не завершение всех пунктов общего TODO.

## Что изменено

- Проект выбирается в общей шапке. Адрес сохраняет проект и раздел; после перезагрузки открывается тот же раздел. Смена проекта с несохранёнными изменениями предлагает сохранить, отказаться или остаться. Переход к персонажу/кадру выполняется после завершения этого выбора.
- GET `/api/projects/{id}/workspace-location` возвращает существующую связь с производственной папкой: проект → серия → сцена → кадр. В шапке страницы показывается путь и возврат к раскадровке. Доска сохраняет выбранную серию, положение прокрутки и выделяет открытый кадр.
- Видео и звук получили самостоятельные страницы. Ранее обе кнопки вели в общий экран «Идея». Библиотека изображения для видео остаётся в том же проекте.
- Лента заданий отменяет старый GET при смене проекта, игнорирует поздние ответы и обновляется сразу после refresh. Повтор после сетевой ошибки касается чтения статусов, не создания оплачиваемых заданий. Запросы опроса одного задания не перекрывают друг друга. Списки изображений обновляются при смене статуса, даже если число заданий не изменилось.
- Сигнал отмены вызывающего кода теперь совмещён с таймаутом API. Индикатор связи восстанавливается после успешной загрузки ленты/проекта.
- Черновик состояния сохранённого проекта сохраняется локально. При открытии выполняется существующее трёхстороннее слияние с серверной версией. При конфликте серверная версия не заменяется автоматически: пользователь выбирает восстановление для проверки или серверную версию. Восстановление не отправляет генерацию. Отдельный черновик «Кадров» из предыдущего этапа сохранён.
- «Кадры» занимают оставшуюся высоту под фактической шапкой, без второго 100vh и минимальной высоты старого main. Поле промпта остаётся внизу рабочей области. Изображения показываются целиком. На среднем окне модели становятся горизонтальной полосой; на телефоне секции идут вертикально.
- Исправлен общий каркас: навигация больше не создаёт 40 строк сетки и пустое место под страницами. На телефоне действия шапки переносятся.
