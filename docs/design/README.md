# Макеты интерфейса GremoVOD Studio (16.10.2026)

Статичные HTML-макеты 1440×900 (телефон 390×844), стили встроены. Открывать в браузере: чтобы подтянуть шрифт Onest, нужен интернет. Файл `support.js` (рантайм конструктора макетов) в репозиторий не входит; он нужен только редактору холста, для просмотра не обязателен.

- `Main.dc.html` — 1. «Создать» (десктоп): референсы | результаты + строка промпта | модели.
- `Board.dc.html` — 2. Доска сцен и кадров + окно кадра справа.
- `Mobile.dc.html` — 3. Телефон: внешняя генерация (ChatGPT) в три шага, нижняя навигация.
- `Workflow.dc.html` — 4. Воркфлоу: узлы, типизированные порты и связи.
- `canvas.json` — расположение макетов на холсте.

Токены: фон `#0E0F12`, панели `#16181D / #1E2128 / #13151A`, рамки `#2A2E37 / #22252C`, текст `#ECE8DF`, приглушённый `#8B8F99`, акцент `#F2B134`, успех `#5EC4B6`; шрифт Onest; скругления 10–20 px.
Реальные экраны в `frontend/src` сделаны по этим макетам и могут отличаться деталями.
