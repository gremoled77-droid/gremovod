# Дизайн-система сериала «Грэм» (GremoVOD)

Для самого мультсериала: титры, заставка, плашки. Интерфейс студии — отдельно (`frontend/src/design.css`).

## Вайб
Минск 90-х, грязноватый реализм, тёплый тёмный. Свет — натриевые фонари и приборка ВАЗ-2106, не экран.

## Токены
Файл [tokens.css](tokens.css), превью — [preview.html](preview.html) (открыть в браузере).

| Роль | Токен | Значение |
|---|---|---|
| Фон | `--s-night` / `--s-asphalt` / `--s-soot` | #15110d / #221c16 / #2e261e |
| Текст | `--s-paper` / `--s-paper-dim` | #e8dcc0 / #b3a487 |
| Главный акцент | `--s-sodium`, `--s-taxi` | #e8a33d, #f2b134 |
| Тревога, ржавчина | `--s-brick` | #9a4b2f |
| Панельный подъезд | `--s-panel` | #5f7a6e |
| Кузов ВАЗ-2106 | `--s-lada` | #c9b98a |

Шрифт — Onest (уже лежит в `motion/assets/Onest.ttf`). Заголовки: 800, капсом. Плашки: 700. Подписи: 500.

## Правила
- Чёрный и белый чистыми не бывают: только `night` и `paper`.
- Акцент один на кадр: либо натрий, либо кирпич. Не больше 10% площади.
- Шашечки такси — фирменный знак плашки (см. `motion/lower-third`).
- Поверх всего плёночное зерно (`--s-grain`) и лёгкая виньетка; без свечения и градиентов-«неона».
- Безопасная зона `--s-safe`; каждая плашка проверяется в 16:9 и 9:16.

## Чего не делаем
- Неоновый киберпанк: фиолет, циан, глоу.
- «Русский» стиль: хохлома, матрёшки, берёзки, кириллица «под старину», красно-золотое.
- Глянец и чистые тени.

## Героев пока двое
Грэм и ВАЗ-2106. Цвет Грэма — `paper` и `sodium`, машины — `lada`. Остальных добавлять сюда же, по цвету на героя.

## Как вшить (проекта-приёмника нет)
1. Для плашек и заставки в `motion/`: скопировать `tokens.css` в `motion/assets/`, поправить путь шрифта на `url('Onest.ttf')`, подключить `<link rel="stylesheet" href="assets/tokens.css">` и заменить жёсткие цвета в `intro/index.html` и `lower-third/index.html` на `var(--s-*)`.
2. Для нового сайта или экрана сериала: положить `tokens.css` в проект, подключить до остальных стилей, использовать только токены.
3. Сверить результат с `preview.html`.
