# Сохраняемая доска раскадровки — первый этап, 16.10.2026

Верхняя кнопка «Раскадровка» открывает рабочую доску на всю ширину. «Раскадровка · демо» остаётся отдельным прототипом. Общий проект GremoVOD выбирается по умолчанию при наличии; далее выбирается серия. Существующие технические материалы не превращались в сюжетную серию и тестовый сценарий в рабочую БД не импортировался.

## Реализовано

- Чтение существующей иерархии production_nodes: серия → episode/сцена → frame. Повторной иерархии нет.
- Текст каждой сцены и превью кадров. Показывается последнее изображение файла кадра с явной подписью «не утверждено»; это ещё не выбор финального дубля.
- Переход из сцены или кадра в соответствующую папку с описанием, референсами и файлами. Общие персонажи и локации доступны из списка библиотеки проекта.
- Создание серии и кадров через существующие маршруты папок. Открытие кадра использует прежнюю привязку production_links/создание рабочего проекта кадра.
- Серверный предпросмотр сценария по заголовкам «Сцена N — Название». Сохранение добавляет новые сцены; исходные номера заголовков служат разметкой, номера папок продолжают существующую последовательность. Текст не переписывается моделью.
- Импорт всех сцен одной транзакцией, стабильные ID, защита от устаревшего снимка доски и повторной отправки request_id. Конфликт имён не перезаписывает существующие сцены.
- Папки сцен и Markdown-текст создаются вместе с импортом; при ошибке до commit новые записи откатываются, созданные этой попыткой файлы/пустые папки удаляются без рекурсивного удаления. Уже существующие папки не затрагиваются.
- Полный текст каждой отправки сохранён в storyboard_imports (журнал импорта, не новая модель сцен), копия — в 01_Сценарий серии с ID импорта. При ошибке записи этой дополнительной копии UI получает предупреждение; исходник в БД остаётся. Поле ввода после открытия показывает последний импорт, а до первого импорта — заметки серии.

## Проверка и границы

12 тестов прошли: 5 новых для доски и 7 существующих production-тестов. Новые проверки покрывают сохранение источника/папок, идемпотентность, чужую серию, конфликт версии, откат при конфликте на диске, неправильный ввод, сохранность старых кадров и их медиа. Использована временная БД/медиакаталог, провайдеры запрещены тестовым окружением. TypeScript/Vite build прошёл с прежним предупреждением о размере JS.

В живом браузере проверены чтение рабочих данных, серверный предпросмотр двух сцен без сохранения и переход к правильной папке сцены. Сервер перезапущен для нового маршрута. Резервная копия перед изменениями: runtime/backups/before-storyboard-20261016.zip (БД и затронутые исходники до изменения; медиа/ключи не включены).

Следующие этапы: привязать конкретных участников и локации к каждой сцене; окна редактирования в контексте доски; адресный возврат GPT; выбранные превью/дубли и порядок; сохранение черновиков ввода при уходе со вкладки. Сейчас библиотека общая, а несохранённый текст сценария живёт только во вкладке до ухода/перезагрузки. Автоматической генерации из доски нет. Генерации доступны после открытия кадра в существующей студии; платные вызовы в этом этапе не выполнялись.
