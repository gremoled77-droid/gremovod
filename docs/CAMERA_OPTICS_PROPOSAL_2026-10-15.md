# Камера и оптика: предложение для AI Workflow Studio

Обновление: выбор камеры/оптики реализован в [стартовом меню](PROMPT_START_MENU_2026-10-15.md). Ниже сохранено первоначальное предложение; окончательное хранение настроек и путь передачи в GPT описаны в новом документе.

Статус: предложение после просмотра живого интерфейса Higgsfield 15 октября 2026. В этом шаге код модуля не менялся, генерации не запускались.

## Что действительно увидели

В режиме Image на `https://higgsfield.ai/generate` кнопка непосредственно слева от Generate называлась `Camera Lens · Auto`. Она открыла `Camera settings` с двумя вертикальными каруселями. Просмотрены следующие варианты, затем восстановлены исходные Auto / Auto:

- CAMERA: Auto, Modern, 35mm Film, 8mm Film, DV Camcorder.
- LENS: Auto, Clean Sharp, Anamorphic, Vintage Anamorphic, Warm Vintage, Halation Vintage.

Повторяющиеся карточки в карусели — циклическое прокручивание, не дополнительные варианты. В этом конкретном фото-диалоге не было отдельных контролов фокусного расстояния и диафрагмы. В [официальном описании Cinema Studio 4.0](https://higgsfield.ai/blog/ai-video-camera-control) диафрагма описана отдельно: Auto, f/1.4 Wide Open, f/4 Moderate, f/11 Deep Focus. Наличие её в справке не означает наличие в просмотренном поповере.

`35mm Film` — выбор плёночного характера камеры. `35 мм` в выборе объектива — фокусное расстояние; эти два параметра нельзя объединять.

## Как внедрить в нашу студию

Добавить компактную кнопку **«Камера и оптика»** рядом с настройками фото, перед подготовкой промпта. В свёрнутом состоянии она показывает выбранную пару, например `Современная / Чистая резкость`. В раскрытом — две группы визуальных карточек: «Характер камеры» и «Рисунок объектива». Крупность, ракурс, свет и движение камеры остаются самостоятельными настройками.

Для карточек нужны русское название, короткое описание эффекта и понятный пример на одинаковой сцене. Иконка настоящего устройства сама по себе плохо объясняет результат. В первом варианте допустимы собственные условные схемы; фото-примеры следует отдельно подготовить и утвердить. Не выдавать CSS-эффект за физическую симуляцию линзы и не использовать миниатюры Higgsfield как собственные материалы.

Предлагаемый каталог камер:

| ID | Название у нас | Предлагаемое назначение |
|---|---|---|
| auto | По референсу | Не добавлять оптическую стилизацию |
| modern | Современная цифровая | Базовый чистый вид сериала |
| film-35 | Киноплёнка 35 мм | Сдержанная плёночная фактура для выбранной сцены |
| film-8 | Плёнка 8 мм | Намеренная ретро-вставка или воспоминание |
| dv | DV-камера | Намеренная бытовая цифровая запись |

Предлагаемый каталог оптики, с описанием эффектов по официальной справке Higgsfield и нашими рекомендациями применения:

| ID | Название у нас | Эффект / применение |
|---|---|---|
| auto | По референсу | Сохранить существующий рисунок |
| clean | Чистая резкость | Читаемые лица, минимум выраженных оптических артефактов |
| anamorphic | Анаморфотная | Киношный рисунок бликов/боке, отдельные установочные планы |
| vintage-anamorphic | Винтажная анаморфотная | Более выраженный характер оптики для отдельной сцены |
| warm-vintage | Тёплая винтажная | Мягкое тёплое впечатление, эмоциональные планы |
| halation-vintage | Винтажная с ореолами | Свечение вокруг ярких огней; осторожно в ночном такси |

Анаморфотный рисунок не меняет автоматически соотношение сторон, не добавляет чёрные полосы и не растягивает персонажей. Тёплая линза не переносит сцену из дня в ночь и не заменяет световую схему. Плёночный характер камеры не меняет дату действия, одежду, салон или стиль персонажей.

## Данные и промпты

Предлагается отдельное необязательное `state.optics`:

```json
{
  "capture_id": "modern",
  "lens_id": "clean",
  "strength": "subtle"
}
```

Не следует помещать оптику в `state.camera`: это уже контракт 19 движений. Не следует ограничивать её `composition`, потому что текущий контекст композиции преднамеренно выключен для видео.

Нужен небольшой `backend/optics.py`: каталог, валидация, формирование инструкции, подпись настройки. В `FramePanel.tsx` подключается выбор оптики, в контекст фото — отдельный `optical_look`. Состояние и снимок выбранной оптики проходят через существующий путь сохранения проекта и подготовки промпта. Auto ничего не дописывает и сохраняет совместимость прежних проектов.

Для видео исходное правило — наследовать оптику утверждённого кадра. Инструкция сохраняет рисунок начального кадра; выбор движения остаётся независимым. Смена камеры или линзы после утверждения фото требует пересобрать/проверить кадр, иначе в видео возможно нежелательное изменение картинки. Отдельно хранить снимок оптики утверждённого кадра, чтобы новая глобальная настройка не приписывалась старому изображению.

На первом этапе наши провайдеры получают конкретные текстовые описания эффектов. Передавать `camera_model_id` или `camera_lens_id` в произвольные API нельзя: такие поля допустимы только для адаптера провайдера, где они документированы. Поддержка оптики в тексте промпта не равна точной физической симуляции или гарантии одинакового результата между моделями.

После первого этапа — расширенные настройки: ориентир угла обзора/фокусного расстояния, глубина резкости и объект фокуса. Числовые значения необходимо явно называть условными ориентирами, а не настройками реальной камеры. По умолчанию проще предлагать «оба героя читаемы / акцент на одном герое / весь салон»; не размывать второго собеседника в общем плане автоматически.

## Старт для GremoVOD

- Базовый комплект: современная камера + чистая оптика, сохранение утверждённого стиля героев.
- Общий разговор: оба героя читаемы, умеренно широкий вид без деформации лиц по краям.
- Отдельная реплика: акцент на говорящем, умеренное отделение от фона.
- Ночной Минск: прежняя световая схема салона; ореолы и анаморфотные блики только по явному выбору, лица остаются читаемыми.
- 8 мм и DV — отдельные стилизованные вставки; не применять их ко всему сериалу автоматически.

Порядок реализации: каталог и компактный выбор → сохранение/подписи/контекст фото → наследование от утверждённого кадра в видео → собственные сравнимые визуальные сэмплы → расширенные настройки фокуса. Проверки: Auto не меняет прежние промпты; оптика не подменяет движение или ракурс; смена оптики делает прежний промпт неактуальным; запоздалый ответ сохраняет исходный снимок; анаморфотный пресет не меняет аспект; общая сцена сохраняет читаемость обоих героев.
