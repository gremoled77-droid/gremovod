# Проверка по чеклисту Claude — 15 октября 2026

Сверено с исходным аудитом «Аудит AI Workflow Studio: как улучшить проект для мультсериала», приложенным пользователем как `Вставленный текст.txt`. Проверка по текущему коду, изолированным тестам и локальной БД. Рекомендации аудита рассматриваются как критерии проверки; сравнения конкурентов и тарифные утверждения из вложения заново не подтверждались.

**Итог:** базовые защиты и доставка API-результатов реализованы. Модель сериала реализована частично. Весь аудит закрытым считать нельзя. Отключение платного LLM-резерва устраняет неподтверждённые вызовы, но не завершает его подключение. Папки раскадровки не заменяют доску, дубли и состояния кадров.

## Семь доказанных ошибок исходного аудита

| № | Проблема | Статус и подтверждение |
|---|---|---|
| 1 | Чужой Host/Origin может читать и запускать API | Исправлено: `backend/security.py`; тест `test_local_session_rejects_foreign_hosts_origins_and_missing_token`, в том числе multipart. Это защита от посторонних сайтов, не от программ с доступом к компьютеру владельца. |
| 2 | Одних approved/max_cost_usd недостаточно | Основная ошибка исправлена: HMAC проекта/payload/цены/срока, серверные бюджеты и транзакционное резервирование. Проверены подмена/истечение и конкурентные отправки. Общего бюджета серии пока нет. |
| 3 | Агенты и чат делают платные вызовы без проверки | Обход закрыт: `/api/chat`, `/api/llm/chat`, `/api/compose`, `/api/agents/run` возвращают 503 до вызова провайдера. Полноценная работа LLM-резерва с проверенной стоимостью ещё не реализована. |
| 4 | submission_unknown без восстановления | Исправлено для PiAPI: `backend/job_recovery.py`, проверка существующего Task ID через GET, сверка модели/типа/промпта, подтверждение, защита от повторной привязки. Неопределённые отправки без ID автоматически не пересоздаются. Для синхронного TTS такая привязка не реализована; повторная отправка того же ID блокируется. |
| 5 | Старый JSON затирает серверные изменения | Исправлена проверенная ситуация: revision/base_revision, 409, трёхстороннее объединение независимых правок; конфликт одного поля сохраняет локальный черновик. 3 отдельных теста объединения прошли. Это ещё не автосохранение и не восстановление последнего проекта. |
| 6 | Отключённые модели дают KeyError/500 при duration | Исправлено: launch_enabled проверяется до чтения схемы; отдельный тест для wan-3.0, ltx-2.5, kling-3.0. |
| 7 | Неполная фактическая стоимость LLM | Не исправлено полностью: оценки и фактические суммы разделены, но автоматического тарифицирования LLM и подтверждения списаний нет. В живой БД у двух API-задач фактическая стоимость не введена. Отключение новых LLM-запусков не закрывает исторический учёт. |
