# Этап «Продюсер»: контракт «идея → сценарная структура»

Минимальный проверяемый контракт одного производственного этапа GremoVOD.
Этап отвечает за один переход: **идея → сценарная структура** (логлайн,
драматургические биты, план сцен, допущения).

Второго сценарного движка не появилось. Этап собран из уже существующих
компонентов:

| Что взято | Откуда |
|---|---|
| Драматургические правила (фон) | `skills/gremovod-screenplay` → `backend/idea_background.py` |
| Версия правил подсказок | `backend/prompt_rules.py` (`RULES_VERSION`) |
| Канон персонажей | состояние проекта (`state['characters']`), поле `identity` |
| Референсы персонажей | таблица `character_assets`, только утверждённые категории |
| Библия мира / Style Library | выбранные автором поля, приходят во входе |
| Модель и провайдер | `backend/model_catalog.py` (реестр решает, не клиент) |
| Оценка, подпись, лимит, журнал | `backend/llm_guard.py` + `backend/security.py` |

## Маршруты

| Маршрут | Что делает |
|---|---|
| `POST /api/producer/estimate` | Собирает пакет данных, считает цену, выдаёт `quote_token`. Для MOCK цена нулевая и токена нет. |
| `POST /api/producer/run` | Запускает этап. MOCK — локально и бесплатно; платный путь требует `approved`, `quote_token`, `max_cost_usd`, `request_id`. |

## Вход

```json
{
  "project_id": "b7f1c0d2",
  "idea": "Грэм берёт ночной заказ: довезти пассажира из аэропорта и не задавать вопросов.",
  "character_ids": ["grem"],
  "reference_ids": [],
  "world": {"city": "Минск", "optics": "дождь, мокрый асфальт"},
  "duration_seconds": 45,
  "language": "ru",
  "constraints": ["Без говорящих животных"],
  "provider": "mock",
  "model": "mock-producer"
}
```

Обязательны только `project_id` и `idea`. Остальное имеет значения по умолчанию:
`provider: "mock"`, `model: "mock-producer"`, `duration_seconds: 60`,
`language: "ru"`, пустые списки персонажей, референсов и ограничений.

Для платного запуска `ProviderRun` добавляет поля подтверждения:

```json
{
  "approved": true,
  "quote_token": "<подпись из /estimate>",
  "max_cost_usd": 0.3621,
  "request_id": "9f2c41ab7d3e4056"
}
```

`provider` и `model` сверяются с реестром: модель вне реестра и провайдер,
который этой модель не обслуживает, отклоняются (400). Провайдера нельзя
подменить — его выбирает `model_catalog.llm_spec`.

## Выход

```json
{
  "stage": "producer.structure",
  "logline": "[Грэм] берётся за задачу из идеи «Грэм берёт ночной заказ…», но главное препятствие пока не определено.",
  "beats": [
    {"id": "b1", "stage": "setup", "summary": "Замысел зафиксирован: …"},
    {"id": "b2", "stage": "development", "summary": "Грэм упирается в препятствие и ищет выход."},
    {"id": "b3", "stage": "climax", "summary": "Грэм делает выбор, который меняет его положение."},
    {"id": "b4", "stage": "ending", "summary": "Цена выбора названа, история закрыта."}
  ],
  "scenes": [
    {"number": 1, "title": "Сцена 1", "duration_seconds": 15, "summary": "…",
     "character_ids": ["grem"], "beat_id": "b1"}
  ],
  "assumptions": [
    "MOCK: реплики не написаны — на их месте краткое описание действия.",
    "MOCK: хронометраж распределён равномерно, реальный тайминг не измерен."
  ],
  "prompt_version": {
    "stage": "producer.structure",
    "revision": "78e04aaa7589",
    "rules_version": "2026-10-17.1",
    "background_version": "8ae6859f2e46"
  },
  "model": {
    "id": "mock-producer",
    "label": "Локальный MOCK (без обращения к провайдеру)",
    "provider": "mock",
    "price_in": 0.0,
    "price_out": 0.0,
    "paid": false
  },
  "cost_usd": 0.0,
  "estimated_usd": 0.0,
  "external_calls": 0,
  "payload_summary": {
    "idea_chars": 79,
    "character_ids": ["grem"],
    "reference_ids": [],
    "world_keys": ["city", "optics"],
    "world_dropped": [],
    "world_truncated": [],
    "constraints": 1,
    "payload_chars": 306

```

`revision` — хеш собранного промпта, `rules_version` — версия правил
подсказок, `background_version` — версия сценарного фона. По ним видно, каким
промптом получен результат.

## Режимы

**MOCK** (`provider: "mock"`, `model: "mock-producer"`) — локальная
детерминированная структура. Сети нет, ключ не нужен, `cost_usd = 0`,
`external_calls = 0`, в журнале расходов ноль строк. С него начинают: контракт
проверяется без затрат. MOCK — тестовый провайдер этапа, а не модель в
реестре: в `LLM_MODELS` его нет, и цена у него нулевая по определению.

**Платный** — оценка → подпись → подтверждение → вызов через
`llm_guard.guarded_chat`. Резерв в журнале расходов, лимит проекта и дня,
идемпотентность по `request_id`.

## Строгая проверка ответа

Принимается только объект JSON с ровно четырьмя полями: `logline`, `beats`,
`scenes`, `assumptions`.

| Проверка | Нарушение |
|---|---|
| Ответ — JSON-объект | 502 |
| Набор ключей совпадает, лишних нет | 502 |
| `logline` — непустая строка до 600 символов | 502 |
| `beats` — 1…12 штук, `stage` из `setup/development/climax/ending` | 502 |
| `scenes` — 1…24 штуки, `number` идёт подряд с 1 | 502 |
| `beat_id` сцены есть среди битов | 502 |
| `character_ids` сцены есть среди выбранных персонажей | 502 |
| `duration_seconds` — целое число секунд | 502 |

Сообщение об ошибке понятное и содержит причину:

```json
{"detail": "Ответ модели не соответствует контракту этапа: поля не соответствуют контракту (scenes.0.beat_id: String should match pattern ...). Платный повтор автоматически не выполняется. Фрагмент ответа: …"}
```

**Автоматического платного повтора нет.** Ответ уже оплачен, второй вызов —
это новая оплата, поэтому при негодном ответе этап останавливается с 502 и
ждёт решения человека. Повтор запускается вручную и оплачивается отдельно.

## Что уходит в LLM

Только то, что автор выбрал:

- идея (до 3000 символов);
- текстовый канон выбранных персонажей: `id`, `name`, поля `identity` (до 300 символов на персонажа);
- выбранные **утверждённые** референсы: `asset_id`, `character_id`, `note` (до 120 символов);
- выбранные поля библии мира: до 8 ключей, 300 символов на значение, 1500 символов суммарно;
- длительность, язык, ограничения (до 8 штук по 200 символов).

Не уходят: изображения и файлы, ссылки на медиа, история сообщений, остальные
персонажи, неутверждённые референсы, поля проекта сверх выбранных.

`payload_summary` в ответе показывает, что именно попало в запрос, а также
`world_dropped` и `world_truncated` — если лимиты обрезали библию мира,
это видно, а не теряется молча.

Отказ до обращения к провайдеру (400):

- персонажа нет в проекте;
- референс не найден, не утверждён (`candidate_generations`) или относится к невыбранному персонажу;
- референс принадлежит другому проекту;
- модель вне реестра или провайдер не обслуживает эту модель;
- нет подтверждения, подпись не совпадает, `request_id` короче 8 символов.

## Чего этап не делает

- Не сохраняет результат в отдельную таблицу: контракт отдаёт структуру и
  метаданные. Запись в проект — следующий шаг, его ещё нет.
- Не пишет реплики и не монтирует: это план сцен, не сценарий.
- Не судит художественно: вердикта «хорошо/плохо» нет, есть только проверка
  формы.
- Не трогает другие этапы (мир, персонажи, кадры, звук, релиз).
- Не подключён к экрану «Идея» во фронтенде: контракт живёт на уровне API.

## Проверки

`backend/test_producer_stage.py` — 14 тестов: контракт MOCK, детерминированность
и нулевая стоимость, отбор персонажей и утверждённых референсов, обрезка
библии мира, строгая проверка формы ответа, отказ по отсутствию подтверждения
или с подменённой подписью, платный запуск с записью в журнал расходов,
состав переданного провайдеру пакета и отсутствие автоматического повтора при
негодном ответе.

Красные прогоны зафиксированы и откачены: отключение проверки ключей и
`extra='forbid'` (лишнее поле проходит), отключение проверки утверждённости
референса, автоматический повтор платного вызова (2 вызова вместо 1) и
передача всего состояния проекта в пакет.
