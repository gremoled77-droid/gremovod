# Исправления корзины и черновика «Кадров» — 16.10.2026

Исправлены три подтверждённых дефекта из CODEX_REVIEW_CLAUDE_2026-10-16.md. Новый дизайн Claude Code сохранён. App.tsx, WorkflowPanel.tsx, design.css, main.tsx и другие ранее незакоммиченные правки не редактировались этой задачей.

## Изменения

- backend/temp_cleanup.py: ручное перемещение и автоматическая очистка используют общий move_to_trash. BEGIN IMMEDIATE берётся до чтения актуального ассета и проверки его связей. Автоматическая очистка повторно проверяет favorite, keep, возраст и тип/провайдера после сканирования кандидатов. Установка сердечка также выполняется под блокировкой записи.
- При ошибке БД после перемещения оригинал возвращается из корзины; независимый новый файл по исходному пути не перезаписывается. Имена файлов корзины уникальны. Это компенсация обрабатываемых ошибок, а не гарантия атомарности файловой системы и SQLite при внезапном отключении питания.
- frontend/src/CreateScreen.tsx и createDraft.ts: черновик хранится локально по projectId. Сохраняются промпт, модели, параметры, ID референсов, описание движения и параметры видео. Переход на другой проект создаёт отдельный экземпляр редактора. Подтверждения, request_id и очередь платных отправок не сохраняются и автоматически не запускаются.
- Ошибка доступа/переполнения localStorage показывает предупреждение; повреждённый черновик не мешает открытию экрана. Пустой промпт сохраняется корректно.

## Проверки

- 119 серверных тестов прошли (unittest discover), включая четыре новые проверки: изменения защиты после сканирования, отказ для используемого файла/одновременное удаление/восстановление, удержание блокировки при проверке связей, восстановление оригинала при отказе DELETE.
- 13 фронтенд-тестов прошли. Три новых проверяют восстановление входов без платной очереди, независимость проектов и очистку текста, отказ/повреждение хранилища.
- TypeScript/Vite build прошёл.
- В живом браузере промпт и один референс восстановились после перехода «Кадры → Старт → Кадры» и после перезагрузки. Тестовый текст и выбор референса затем убраны, генерации не запускались. Скриншот: create-draft-restored-2026-10-16.png.
