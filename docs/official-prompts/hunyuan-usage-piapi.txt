How to Make a Hunyuan API Call
Hey guys! In order to help users create task with Hunyuan API more fluently, here I would like to give some examples to demonstrate how to choose each task type based on you need and make a perfect API call.
Here we go!
hunyuan-txt2video
#
{
"model"
:
"Qubico/hunyuan"
,
"task_type"
:
"txt2video"
,
"input"
:
{
"prompt"
:
"A cat walks on the grass, realistic style."
}
,
"config"
:
{
"webhook_config"
:
{
"endpoint"
:
""
,
"secret"
:
""
}
}
}

:
"A cat walks on the grass, anime style."
,

:

{
"lora_type"
