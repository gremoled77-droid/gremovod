This is the api for Kling's video generation API. Kling 3.0 is an upgraded version of Kling 2.6.
Kling 3.0 Turbo
is a faster sibling of 3.0 — same visual pipeline with quicker generation. It carries a modest price premium over 3.0 without audio (roughly +30% at 720p, +27% at 1080p) and does not support native audio generation.

Price examples
3.0, 720p, 10s, no audio: 10 * $0.10 = $1.00
3.0, multi-shots (shot1 2s + shot2 3s), 720p with audio: (2 + 3) * $0.15 = $0.75
3.0-turbo, 720p, 10s: 10 * $0.13 = $1.30
3.0-turbo, 1080p, 5s: 5 * $0.19 = $0.95
Version selection
version: "3.0"
— full 3.0 feature set (multi-shots, native audio)
version: "3.0-turbo"
— faster 3.0 pipeline;
no
enable_audio
, no
multi_shots
. Use it when generation speed matters and you don't need audio
Notes
Support flexible duration between 3 – 15 seconds (both 3.0 and 3.0-turbo)
If multi shots used (3.0 only), params
prompt
and
duration
will be ignored
Maximum 6 multi shots, total duration should not exceed 15 seconds
enable_audio: true
combined with
version: "3.0-turbo"
is rejected with a validation error
Response struct for both 3.0 and 3.0-turbo uses the same compact schema:
output.video
only. See
