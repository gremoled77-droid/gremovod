## Подтверждённые ошибки и исправления в проверочной копии

1. main.py передавал kind=image в takes с CHECK(kind IN ('keyframe','video')). Генерация картинки с shot_id давала HTTP 500 до обращения к провайдеру после записи submitting/резерва. Исправлено преобразование image → keyframe, создание дубля включено в ту же транзакцию, что задача и резерв.
2. add_take принимал PNG как видеодубль. Добавлено сравнение kind ассета с видом дубля; чужие ассеты по-прежнему не принимаются.
3. shot_gate проверял только статус. Даже после утверждения кейфрейма принимался другой URL входной картинки. Теперь первым референсом должна быть исходная ссылка этого кейфрейма либо его действующая hosted_url; сам кейфрейм должен существовать в нужном эпизоде и быть изображением.
4. select_take оставлял прошлый выбранный дубль с decision=used. Теперь прежний выбор снимается, если этот ассет не выбран другим шотом; ручные решения по остальным ассетам сохраняются.

После исправлений повторно прошли все 50 тестов и отдельно 4 новые регрессионные проверки. Изменённые фикстуры явно задают тип видео и URL утверждённого кейфрейма. Проверочная копия не подключена к рабочей БД и не является готовой заменой рабочей студии.

## Уже перенесено в рабочую студию

- SQLite timeout=10 секунд и PRAGMA foreign_keys=ON для каждого соединения.
- Проверка Host возвращает 403, включая некорректный порт/скобки; сохранены локальная сессия, проверка Origin на чтение и запись, запрет запуска платного LLM без серверной цены. Список разрешённых хостов не расширен.
- Экономика отдельно выдаёт llm_calls_unpriced, unknown_generation_cost_count, media_costs_complete. Общий costs_complete по-прежнему ложный, пока есть неизвестные фактические расходы. Так не возникает ложной полной стоимости ролика при неучтённых LLM-вызовах.
- Интерфейс экономики поясняет различие, если такие запросы есть.

Все 71 тест рабочей версии прошли; TypeScript/Vite build прошёл. Есть предупреждение Vite о размере общего JS более 500 kB, ошибок сборки нет. Рабочий сервер перезапущен. Проверено по HTTP: health=200, чужой Host=403, чужой Origin=403, поля экономики присутствуют. Платные генерации и внешние загрузки не выполнялись.
