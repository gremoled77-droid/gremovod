# Задача каждой ноды

Версия 1.0-review, 19.10.2026. 43 узла основного процесса и 9 общих сервисов. Это логические ноды/подпроцессы; физическое число n8n nodes уточняется при реализации. Ни один NEW здесь не объявлен созданным.

Общие требования: все внешние модельные вызовы проходят S04/S05, все записи — S01/S08, навыки — S02. FAIL направляется в N42, BLOCKED в N43; после исправления выполняются нужные повторные проверки. Сервисы CALLER возвращают управление вызывающему узлу. DYNAMIC/RESUME/END — управляющие исходы, не скрытые URL или узлы.

## N01 — Идея автора

- **Исполнитель:** автор / вход.
- **Вход:** Идея, задача, при наличии файлы и ограничения.
- **Задача:** Принять исходную формулировку без переписывания; присвоить project_id/task_id/run_id; зарегистрировать файлы и ожидаемый формат выпуска.
- **Выход:** idea.original + assets_manifest.
- **Приёмка:** Оригинал сохранён, типы файлов определены; секреты не попали в промпт.
- **Далее:** PASS → N02; FAIL → N43; BLOCKED → N43.
- **Реализация:** NEW.

## N02 — Проверка входов

- **Исполнитель:** код.
- **Вход:** N01, права доступа, доступность файлов.
- **Задача:** Проверить проект, доступ, размер, целостность и возможность чтения; отделить пожелания от утверждённых фактов. Не требовать готовый сценарий на входе идеи.
- **Выход:** intake.validated / missing_inputs.
- **Приёмка:** Всё необходимое для разработки идеи доступно; медиа-пути доступны именно исполнителю.
- **Далее:** PASS → N03; FAIL → N43; BLOCKED → N43.
- **Реализация:** NEW.

## N03 — A0: производственный бриф

- **Исполнитель:** A0.
- **Вход:** Идея, ограничения автора, доступный канон, бюджетные условия.
- **Задача:** Зафиксировать замысел, аудиторию, формат/длительность, обязательные события, запреты, свободу разработки и критерии успеха. Спросить только критически недостающее; сформировать понятный план.
- **Выход:** brief.candidate + requirements + research_tasks + stage_plan.
- **Приёмка:** Требования прослеживаются к исходной идее; не добавлен новый канон без пометки; неопределённости видны.
- **Далее:** PASS → N04; FAIL → N42; BLOCKED → N43.
- **Реализация:** ROLE_ONLY.

## N04 — A4: исследование по необходимости

- **Исполнитель:** A4 + инструменты источников.
- **Вход:** Конкретные исследовательские вопросы из N03.
- **Задача:** Если вопросов нет — SKIPPED с причиной. Иначе прочитать реальные доступные источники, вернуть факты/ссылки/пределы знания; не выдавать реконструкцию за факт мира.
- **Выход:** research.report / SKIPPED.
- **Приёмка:** У утверждений есть источники, отсутствующие источники отмечены; результаты не утверждают художественный канон.
- **Далее:** PASS → N05; FAIL → N42; BLOCKED → N43.
- **Реализация:** ROLE_ONLY.

## N05 — Фиксация брифа и критериев

- **Исполнитель:** код + автор при существенном выборе.
- **Вход:** Бриф, результаты исследования, правила мира, выбранный эталон при наличии.
- **Задача:** Зафиксировать ревизию и хэши. Для новых правил/идентичностей запросить явное утверждение автора; разрешённую творческую свободу записать. Если эталона нет — предложить конкретные критерии, не объявлять их утверждёнными автоматически.
- **Выход:** brief.snapshot + requirements_version + canon_scope + review_bar.
- **Приёмка:** Установлено, что обязательно, что допускает варианты и что неизвестно; правила согласованы для данной задачи.
- **Далее:** PASS → N06; FAIL → N42; BLOCKED → N43.
- **Реализация:** NEW.

## N06 — A1: варианты развития идеи

- **Исполнитель:** A1.
- **Вход:** Зафиксированный бриф, канон, исследование и профильные навыки.
- **Задача:** Предложить несколько содержательно отличающихся концепций в согласованном количестве (по умолчанию 3): конфликт, ход событий, комедийный механизм, финал, производственная сложность. Не генерировать медиа.
- **Выход:** concepts[] с ID + tradeoffs.
- **Приёмка:** Варианты отличаются по содержанию, выполняют бриф; новые факты обозначены предложениями.
- **Далее:** PASS → N07; FAIL → N42; BLOCKED → N43.
- **Реализация:** ROLE_ONLY.

## N07 — Критика вариантов

- **Исполнитель:** A6 / A7 / A8 по применимости через S07.

- **Задача:** A6 проверяет задачу; A7 — канон; A8 оценивает драматургический потенциал текста в режиме TEXT_CRAFT, если разрешены модель и критерии. Не оценивает несуществующее видео.
- **Выход:** concept_reviews[] + largest_gaps.
- **Приёмка:** Каждое обязательное требование проверено; замечания привязаны к варианту; текст не выдаётся за медиадоказательство.

## N08 — Выбор концепции

- **Приёмка:** Один ID выбран с причиной и авторизацией выбора; остальные сохранены.

## N09 — A1: сценарий и реплики

- **Исполнитель:** A1.
- **Вход:** Выбранная концепция, бриф, канон, допустимая длительность.
- **Задача:** Разработать сцены, действия, реплики, драматические биты, подготовку и раскрытие. Вернуть варианты спорных решений отдельно; сохранить стабильные ID сцен/реплик.
- **Выход:** script.candidate + scene_ids + dialogue_ids.
- **Приёмка:** История завершена в заданном объёме; реплики привязаны к персонажам; нет скрытого изменения концепции.
- **Далее:** PASS → N10; FAIL → N42; BLOCKED → N43.
- **Реализация:** ROLE_ONLY.

## N10 — Критика сценария

- **Исполнитель:** A6 / A7 / A8 по применимости через S07.
- **Вход:** Замороженный текст сценария, отдельные пакеты требований/канона/текстового ремесла.
- **Задача:** Проверить обязательные события, причинность, канон, ясность, темп и подачу реплик; при FAIL вернуть крупнейшую проблему A1. Текстовое ремесло не требует рендера, но требует разрешения и критериев.
- **Выход:** script.reviewed + stage_verdicts.
- **Приёмка:** Все обязательные для сценария критики PASS на одной версии; канон и публикация не утверждаются этим шагом.
- **Далее:** PASS → N11; FAIL → N42; BLOCKED → N43.
- **Реализация:** NEW.

## N11 — A2: подбор персонажей и локаций

- **Задача:** Подобрать образы персонажей, одежду, локации и постоянный реквизит под смысл сцены; сопоставить реплики с исполнителями; сформировать заявки на недостающие виды/образы.
- **Выход:** casting_plan + location_plan + asset_requests.
- **Приёмка:** Все сцены имеют состав/локацию; выбор объяснён; новые образы остаются кандидатами.
- **Далее:** PASS → N12; FAIL → N42; BLOCKED → N43.

## N12 — Комплект референсов мира

- **Исполнитель:** код + A2 + автор для нового канона.
- **Вход:** Планы N11, оригиналы и утверждённые версии образов/локаций.

- **Выход:** reference_pack.versioned + unknowns.
- **Приёмка:** Лица и пространство не противоречат друг другу; неподтверждённая реконструкция не объявлена каноном; необходимые виды доступны.

## N13 — A2: режиссёрская разработка кадров

- **Исполнитель:** A2; A1 для изменения текста.
- **Вход:** Сценарий, подбор персонажей/мира, референсы.
- **Задача:** Для каждого кадра определить функцию, участников, действие, мизансцену, размер/ракурс, оптику как эффект, камеру, свет, длительность, реплики и актёрскую подачу, звук, связи с соседями. Изменение смысла/текста реплики отправить A1, постановочную подачу решает A2.
- **Выход:** shot_cards[] + scene_geography + performance_notes.
- **Приёмка:** Покрыты все биты/реплики; нет незаметно добавленных событий; ось и география согласованы; смена сценария вызывает N10.
