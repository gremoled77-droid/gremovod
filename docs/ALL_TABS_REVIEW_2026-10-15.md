## Сквозные разделы внутри студии

### Персонажи

Есть имя и описание, профиль каждой модели, референсы по категориям, рабочий образ, архив предыдущего образа. Новый Грэм `5dbe745ff49d4d06af4d4fc4cd36e8e7` выбран основным, старый сохранён.

Нужны общая библиотека сериала, поиск, фильтр категорий и архива, сравнение/восстановление версии, несколько комплектов одежды и ракурсов. Сейчас поле категории определяет загрузку файла, а список «Показать файлы персонажа» выводит все категории вместе. Персонажи остаются привязаны к проекту.

### Видео и камеры

Есть выбор подключённой модели, текст движения, URL кадра, параметры разрешения/формата/длительности по адаптеру. Для Hunyuan используется один кадр и параметры провайдера по умолчанию. Остальные пункты каталога не означают, что генерация уже подключена.

Не реализованы запрошенный каталог движений камеры с мини-превью, монтаж шотов, апскейл и сравнение «дёшево + апскейл» с финальным качеством. Сначала нужны шоты и утверждённые кадры, затем эти функции.

### Звук

Есть локальный импорт, длительность, предложения интервалов по паузам, выбор фрагмента, лёгкая очистка/нормализация и WAV-экспорт. FFmpeg и ffprobe доступны.

Генерация речи через Fish/ElevenLabs и синхронизация с видео ещё не подключены. Полезные дополнения: библиотека разрешённых голосов персонажей, реплики по шотам, прослушивание, версии дублей, музыка/эффекты отдельными дорожками, учёт расходов. Наличие ключа не подтверждает готовность этих функций.

### Галерея и облако

Сохраняются локальные оригиналы, миниатюры, промпты и параметры; доступны отправка в сцену/правку, выбор для видео и решение об использовании в ролике. TempFile.org подключён без ключа; реальная загрузка Грэма и совпадение SHA256 проверены ранее. PiAPI — резервный вариант загрузки.

Нужны названия и теги, поиск, группировка по типу/шоту/версии, единое представление результата вместо повторов в нескольких панелях, срок действия облачной ссылки рядом с кадром и проверка истечения перед платным запуском. Успешный round-trip облачного файла ещё не является проверкой приёма этой ссылки каждой видеомоделью.

## Что обнаружено сейчас

1. **Новый референс, старый видеопромпт.** В Video Lab выбран новый Грэм, но промпт Seedance описывает пустую улицу Минска и запрещает людей. Смена кадра не помечает промпт устаревшим. Добавить привязку версии промпта к исходникам и запрос на пересборку перед оплатой.
2. **Описание костюма осталось старым.** В карточке Грэма написаны тёмные ботинки, хотя рабочий образ содержит синие NB 574. Замена картинки не обновляет текст идентичности. Для нативного контекста у рабочего изображения уже есть приоритет, но противоречие следует показывать и исправлять в описании после утверждения.
3. **Сообщение о сессии может оставаться после восстановления связи.** В основном чате отображалось «Локальная сессия отсутствует» одновременно с доступным API и загруженными заданиями. В ChatGPTPanel/RefinePanel успешный опрос не очищает прежнюю ошибку. Нужны отдельные ошибки соединения и отправки, чтобы исправление связи не скрывало ошибку генерации.
4. **Выбор проекта не переживает перезагрузку.** После обновления открывается пустой новый проект. Нужны восстановление последнего открытого проекта, индикатор несохранённых изменений и локальный черновик/автосохранение. Версионная защита уже есть, но автосохранения нет.
5. **В сцене персонаж не появляется от выбора в боковой панели.** В сохранённом составе сейчас только улица с ролью location. Референсы Character Vault не добавляются автоматически при use_scene. Показывать состав сцены явно и дать кнопку «Добавить текущего персонажа».
6. **«Заменить персонажа» показывается и у фоновых изображений.** Нужен понятный просмотр «было → станет» с указанием выбранного персонажа, чтобы не назначить фон рабочим образом случайно.
7. **Ключи и доступность моделей — разные состояния.** Сейчас ключи PiAPI/Fish/ElevenLabs настроены, но после перезапуска проверка доступа отображается как не выполненная; OpenAI-ключ отсутствует. Удалённые проверки в рамках обзора не запускались.

## Рекомендуемый порядок

1. Согласованность текущей работы: референс/промпт/описание, ошибки сессии, последний проект и локальные черновики.
2. Общие персонажи, мир, локации и реквизит.
3. Сериал → эпизод → сцена → шот → дубли, с миграцией существующего проекта без потери файлов.
4. Утверждение кейфрейма, каталог камер, голоса/реплики и сравнение вариантов.
5. Проверенные тарифы для LLM-резерва, затем исполнение узлов и оценка дешёвых связок с апскейлом.

На момент обзора: 4 медиа-попытки (2 через чат и 2 через PiAPI), 0 отмеченных использованными в ролике; оценка PiAPI $0.142, у 2 задач фактическая цена не введена. Утверждение внешности персонажа не означает автоматическую отметку «использован в финальном ролике».
