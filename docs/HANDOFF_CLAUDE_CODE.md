## Запуск для разработки

- `START_DEV.bat` (или `scripts\start_studio.py --dev`) — бэкенд сам перезапускается после правок в `backend/`. Обычный `START_WINDOWS.bat` — без автоперезапуска.
- Ручной стенд из worktree — на других портах и со своим `STUDIO_DATA_DIR`; рабочую SQLite не трогать (см. `AGENTS.md`). Бэкенду стенда задать `STUDIO_DEV_ORIGINS=http://127.0.0.1:<порт фронта>` (иначе запись отклоняется как «посторонний сайт»), фронту — `STUDIO_API_URL=http://127.0.0.1:<порт бэкенда>`.

## Грабли (стоили времени)

1. Новый экран: класс на `<main>` (`home-main`, `create-main`…) — иначе старый `style.css` сжимает экран (`margin:auto`, сетка 282px).
2. `React.lazy`-константы в `App.tsx` — после всех импортов; хуки от `projectId` — после его `useState` (иначе белый экран).
3. Окна поверх всего (Lightbox) — через портал в `document.body`.
4. Prettier обязателен (`frontend/.prettierrc.json`).
5. PiAPI: GPT Image отвечает base64 и хранит результат ~60 мин — сохранять сразу; MiniMax `resolution` только строчными.
6. Платные вызовы — только по разрешению владельца в текущей сессии, с лимитом.
7. Старый `style.css` задаёт всем `input`/`textarea`/`select` правило со специфичностью выше одного класса: чтобы скрыть или переопределить поле, нужен селектор сильнее (например `.wf .wf-console input.wf-search`).
