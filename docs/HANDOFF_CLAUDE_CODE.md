## 4. Живая проверка PiAPI (16.10.2026, потрачено ≈ $0.5)

Все шесть моделей изображений + MiniMax H3 проверены реальными вызовами; `launch_enabled=True`, `verified_at='2026-10-16'` в `backend/model_catalog.py`. Подробности в `docs/PIAPI_MODELS_2026-10-16.md`. Главное:

- GPT Image 2.0/2.5: эндпоинт `/api/v1/images/generations/async`; ответ на отправку приходит **без обёртки `data`** (task_id в корне) — код оборачивает его в `{'code':200,'data':...}`; статус `GET /api/v1/task/{id}` с обёрткой; результат — `output.data[].b64_json` (base64), URL нет. Результат хранится у PiAPI ограниченно (GPT — 60 мин): сохранять сразу.
- Qwen 2.1: `output.image_url` / `image_base64`. Nano Banana 2.1 и Seedream 5 Pro: `output.image_urls`.
- MiniMax H3: `resolution` только **в нижнем регистре** (`480p/768p/1080p`). Результат `output.video_url`.
- Картинки лежат на `img.theapi.app`; домен должен быть разрешён сетью (в облачной песочнице пришлось добавлять в allowlist).
- Цены по факту совпали с каталогом (flare ≈ $0.004, 2.5 standard ≈ $0.012, 2.0 medium ≈ $0.032, Qwen $0.015, Nano 1K $0.03, Seedream Pro 1K $0.068, MiniMax 480p 5 с $0.15).
- **Не проверено вживую:** референсы и правки GPT Image (sunburst), референсы Seedream/Nano, img2video MiniMax.
- Один раз случайно запущен демо-запрос дважды ($0.10 вместо $0.05) — владельцу сказано.
