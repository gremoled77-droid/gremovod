## Запуск для разработки

- `START_DEV.bat` (или `scripts\start_studio.py --dev`) — бэкенд сам перезапускается после правок в `backend/`. Обычный `START_WINDOWS.bat` — без автоперезапуска.
- Ручной стенд из worktree — на других портах и со своим `STUDIO_DATA_DIR`; рабочую SQLite не трогать (см. `AGENTS.md`). Бэкенду стенда задать `STUDIO_DEV_ORIGINS=http://127.0.0.1:<порт фронта>` (иначе запись отклоняется как «посторонний сайт»), фронту — `STUDIO_API_URL=http://127.0.0.1:<порт бэкенда>`.
