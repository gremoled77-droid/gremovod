# ChatGPT, сцены и экономика — 15.10.2026

Основной чат: `01a13e25-939c-7b73-9c0a-669abc8aa6a7`, GPT 6.1 Sol medium.
В студии основной блок ставит локальное задание: подготовка промпта → встроенный
imagegen → загрузка оригинала в библиотеку. Повтор ID не создаёт новое задание.
Сбой после начала генерации не вызывает автоматический платный повтор.

## Что требуется для обработки

Нет поддержанного HTTP API, которым FastAPI мог бы разбудить существующий чат
Codex и получить доступ к его встроенному imagegen. Это не имитируется приватными
эндпоинтами, браузерными токенами или скрытым переходом на платный API.
Обработка автоматическая только во время активного прослушивания очереди чатом.
Статус и инструкция запуска видны в интерфейсе. Открытие чата само по себе не
запускает обработчик; пользователь пишет «Продолжай очередь студии».

Транспорт: `scripts/native_chat_worker.py wait --seconds 50`; JSON содержит снимок
контекста, роли исходников, целевую модель и инструкции. Чат сохраняет английский
промпт в UTF-8, вызывает `prompt-ready --job ID --file PATH`, затем без нового
подтверждения создаёт изображение встроенным инструментом и вызывает
`image --job ID --file ORIGINAL`. Для prompt-only генерация медиа не выполняется.
Транспортный ключ остаётся в локальном файле и не показывается пользователю.

Для operation `describe_character` обработчик открывает референсы из context.references через просмотр изображений, следует request.rules и возвращает JSON с шестью полями внешности на русском. Завершение: `scripts/native_chat_worker.py identity-ready --job ID --file DESCRIPTION.json`. Для этой операции не вызывать prompt-ready/imagegen/image; она не является генерацией медиа и не включается в её экономику. Если признаки не видны, явно указать это. Подробности: CHARACTER_REFERENCES_2026-10-15.md.

Фактическая модель и настройка качества встроенного инструмента не раскрываются.
GPT Image 2.5 — целевой запрос, а не доказанный идентификатор результата.
Сохраняются реальные размеры оригинала; искусственное увеличение не используется
для заявления о максимальном разрешении. В UI есть ссылка `codex://threads/ID`
«Править в чате». Поддержка открытия ссылки и выделения областей зависит от версии
настольного приложения. Ручные правки в чате пока не синхронизируются в библиотеку
автоматически: обработчик должен загрузить новый оригинал как новую версию.

## Сцены

Каждый проект сохраняет scene: brief, assets с ролями и заметками, target, prompts.
Исходники выбираются из библиотеки этого проекта. Кнопка «Отправить в сцену»
добавляет ссылку на оригинал, не дублирует файл. Чужие и удалённые ассеты отклоняются.
Встроенный imagegen читает локальные исходники. Для API-видео нужны публичные HTTPS
референсы: загрузка локального оригинала к провайдеру пока не подключена.
Непроверенные API-адаптеры остаются отключёнными, промпты для них доступны.

## Учёт роликов

Проект студии является единицей учёта ролика. API-оценки до запуска и фактические
расходы не смешиваются. Факт вносится по списанию, включая ошибки и неудачные
результаты. Платные API-промпты тоже присутствуют в списке расходов.
Для чата считаются попытки и готовые изображения; стоимость подписки не
распределяется. Отдельно показан гипотетический API-эквивалент выходного изображения.

Сравнение GPT рассчитывается по публичной формуле калькулятора OpenAI и тарифу
$30/млн выходных image tokens, проверенным 15.10.2026. Математическая формула
адаптирована в backend/image_pricing.py; архив JS калькулятора в official-prompts.
Размер берётся из файла, при отсутствии допустимого размера — 1536×1024.
Сценарий качества: GPT Image 2.5 max, GPT Image 2 high. Это допущение для API,
а не обнаруженная настройка чата. Входные image/text tokens и partial images
не включены. Источник: https://developers.openai.com/api/docs/guides/image-generation

«Использовано в ролике» — явная отметка в библиотеке; отправка в сцену не считается
финальным использованием. Выход годных: попытки с хотя бы одним используемым
результатом / завершившиеся попытки генерации, включая ошибки. Ожидающие и
отменённые до запуска задачи не входят. Месячные показатели разделены по моделям.
Это наблюдения, а не доказательство причинного улучшения навыков.

## Официальная база промптов

Архивированы 16 полнотекстовых официальных страниц, публичный калькулятор OpenAI
и официальный архив Wan 3.0 prompt skill с URL, датой и SHA256.
Две JS-страницы блога Qwen помечены needs_review; вместо их пустого содержимого
использовано полное руководство Alibaba Cloud с версиями 2.1 и 3.0.
Профили: GPT Image 2/2.5, Seedream 5 Pro/Lite, Nano Banana 2.1,
Qwen Image 2.1/3.0, Seedance 2.5, Wan 3.0, LTX 2.5, Kling 3.0.
Каждый профиль задаёт порядок, синтаксис референсов, ограничения и список источников.
PiAPI теги @imageN применяются только к Seedance; остальные профили используют
естественные обозначения изображений. Источники и профили: /api/prompt-knowledge.

браузера; открытие по этой кнопке пока не подтверждено.
