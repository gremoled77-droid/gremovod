# Подключения и первый цикл изображений

Проверено 15 октября 2026 года. Работа продолжается в локальной браузерной версии студии.

## Подключения

Вкладка «Подключения» показывает наличие ключа и результат отдельной проверки доступа. GET /api/connections читает только локальные настройки. POST /api/connections/{provider}/check выполняет один GET к фиксированному адресу провайдера, не создавая генерации. Ключи, тело ответа аккаунта и баланс в UI не возвращаются.

Сервер читает переменные окружения либо файлы в корне студии: PIAPI_API_KEY.txt, OPENAI_API_KEY.txt, ELEVENLABS_API_KEY.txt, FISH_AUDIO_API_KEY.txt. Для ElevenLabs также учитывается найденный файл Documents/!GREM TAXI/.secrets/elevenlabs-api-key.txt; путь можно изменить серверной переменной ELEVENLABS_KEY_FILE. Ключи не копируются между файлами. Интерфейс больше не содержит полей ввода ключей.

Приоритет: ключ заголовка для совместимых старых клиентов, затем переменная окружения, затем файл проекта. Для ElevenLabs последний источник — файл проекта «Гремовод». Отсутствующий или некорректный ключ отличается от непроверенного подключения. После изменения ключа предыдущая проверка сбрасывается; после перезапуска сервера подключения проверяются заново. Отпечаток ключа используется только в памяти и не передаётся клиенту.

На реальных ключах прошли проверки PiAPI, ElevenLabs и Fish Audio. Ключ OpenAI не настроен. PiAPI account/info ответил успешно; это подтверждает чтение аккаунта, но не гарантирует доступ ко всем моделям. Генерации и озвучка не запускались.

Адреса проверок и официальные источники:

- PiAPI: GET https://api.piapi.ai/account/info — https://piapi.ai/docs/account-info-api
- OpenAI: GET https://api.openai.com/v1/models — https://developers.openai.com/api/reference/resources/models/methods/list
- ElevenLabs: GET https://api.elevenlabs.io/v1/user/subscription — https://elevenlabs.io/docs/api-reference/user/subscription/get
- Fish Audio: GET https://api.fish.audio/wallet/self/api-credit — https://docs.fish.audio/api-reference/openapi.json

## Изображения

Первый разрешённый адаптер — Seedream 5 Lite: один результат, 2K/3K, ограниченные параметры и до 10 публичных HTTPS-референсов. Пакетные параметры не принимаются. Остальные модели остаются в каталоге для подготовки промптов, но платный запуск отключён до проверки схемы и стоимости. Для Pro документация неоднозначно описывает доплату за референсы; безопасная оценка пока не реализована.

Перед отправкой пользователь сохраняет проект и открывает окно «Подтверждение генерации». Оно получает оценку через POST /api/model-jobs/estimate. Оценка Lite — $0.052 по https://app.piapi.ai/docs/seedream-api/seedream-5, дата сверки 2026-10-15. Нужно самостоятельно указать лимит на одну операцию и отметить согласие. В запросе на сервер обязательны approved, max_cost_usd и уникальный request_id.

Лимит проверяет текущую локальную оценку; это не параметр ограничения списания на стороне PiAPI. Фактическое списание определяется провайдером. Общий бюджет проекта и сверка фактических расходов остаются следующим этапом.

Заявка и согласие фиксируются в SQLite перед внешним запросом. Повтор с тем же request_id возвращает существующую заявку, а несовпадающий запрос отклоняется. При потере ответа статус становится submission_unknown, автоматического повторного создания нет. Нужно проверить историю провайдера, прежде чем создавать новую заявку. Старый POST /api/tasks закрыт, чтобы исключить обход подтверждения. Уже сохранённые проекты и jobs не удаляются.

Поддерживаются немедленный результат и ожидание task_id с ручной проверкой статуса; завершённые задачи повторно не опрашиваются.

## Библиотека

В очереди у готового изображения есть «Сохранить в библиотеку». Сервер получает URL только из сохранённого ответа задания, скачивает оригинал без ключей провайдера, ограничивает размер 20 МБ, проверяет PNG/JPEG/WebP библиотекой Pillow и сохраняет в backend/library. Проверяются публичный HTTPS-адрес и каждый redirect. Пользовательский URL в запрос сохранения не принимается.

SQLite хранит связь с проектом, заданием, индексом результата, моделью, промптом, настройками, размерами, исходной ссылкой и датой. Повторное сохранение не создаёт дубль; отсутствующий локальный файл можно загрузить снова по той же ссылке.

Из библиотеки можно скачать оригинал или выбрать кадр для Video Lab. В проекте сохраняются исходный публичный URL и ID локального ассета. Публичная ссылка может истечь; загрузка локального файла в хранилище видеопровайдера и реальная генерация видео пока не реализованы.

## Проверки

- `npm run build` — успешно; остаётся известное предупреждение Vite о `use client` в ReactFlow.
- `.\.venv\Scripts\python.exe -m unittest backend.test_smoke -v` — 15 успешных тестов.
- `pip check` — конфликтов нет.
- Браузер: видны реальные статусы трёх подключений, оценка Lite и недоступная без согласия кнопка оплаты; ошибок warn/error на проверенных экранах нет.
- Генерация → библиотека → повторное открытие проверены тестовым ответом провайдера и настоящим небольшим PNG в изолированной временной БД. Платная сквозная генерация не проверялась.
- Проверены блокировка Cloudflare 1010, не-JSON ответы, отсутствие ключей в ответах UI, обязательное согласие, недостаточный лимит, защита от повторной отправки, потеря ответа, публичные адреса загрузки и обработка redirect без передачи ключей.

Добавлена зависимость Pillow (установлена 12.3.0) для проверки изображений. Предупреждение Starlette о будущей миграции TestClient/httpx не мешает тестам; отдельная миграция не выполнялась.
