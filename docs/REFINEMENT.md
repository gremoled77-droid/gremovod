# «Допилить» — 15.10.2026

Раздел принимает оригинал из библиотеки или локального PNG/JPEG/WebP, необязательный
дополнительный референс и описание правки. Из библиотеки любого провайдера есть
кнопка «Отправить в GPT Image». Черновик хранится в state.refinement проекта.

POST /api/library/import-image проверяет формат по содержимому, ограничивает размер
20 МБ и сохраняет исходник без генерации. Импорт не считается платной попыткой.
POST /api/chatgpt/jobs с operation=edit получает source_asset_id,
reference_asset_id и edit_instruction. Каждый исходник должен принадлежать проекту.
Оригинал и референс детали имеют разные роли. Общая библия мира и другие профили
персонажей не добавляются к локальной правке.

Путь обработки: GPT 6.1 Sol готовит английскую инструкцию → prompt-ready →
встроенный imagegen редактирует приложенные изображения → image загружает новый
оригинал в библиотеку. Backend дописывает обязательные инструкции сохранения лица,
персонажей, композиции, света и остальных элементов. Исходный файл не перезаписывается.
Новая версия хранит ID родителя, ID референса, текст правки, итоговый промпт и провайдера.
Редактирование учитывается отдельной попыткой в экономике, API-эквивалент отделён
от фактических расходов. Новая версия не утверждается автоматически.

## Договор обработчика чата

При получении operation=edit обработчик обязан:
1. Прочитать request.execution и context.preservation_contract.
2. Просмотреть каждый references[].local_path через view_image.
3. Составить английский промпт изменения, сохранив явно указанные инварианты.
4. Вызвать prompt-ready. Операция остаётся в generating.
5. Вызвать встроенный imagegen в режиме EDIT с referenced_image_paths в исходном
   порядке: Image 1 — оригинал, Image 2 — только референс нужной детали.
6. Загрузить результат image --job ID --file ORIGINAL и показать его в чате.

Запрос модели GPT Image 2.5 не доказывает фактическую версию встроенного инструмента:
она не раскрывается. Размер и качество нельзя произвольно выбрать через данный мост.
Генеративный инструмент не гарантирует пиксельную неизменность вне области правки.
Автоматического пробуждения отдельного чата нет: обработчик должен активно слушать
очередь. Платный API не включается как автоматический запасной путь.

## Проверка

27 backend integration tests проходят, frontend tsc/vite build проходит.
Правка оригинала с отдельным референсом, история версий, изоляция проектов,
отклонение не-изображений, идемпотентность и экономика проверены с синтетическим PNG.
Реальная операция редактирования imagegen в этом разделе пока не запускалась:
пользователь ещё не задал конкретную правку. Реальная новая генерация Грэма через
тот же чат и загрузка оригинала были проверены ранее.
