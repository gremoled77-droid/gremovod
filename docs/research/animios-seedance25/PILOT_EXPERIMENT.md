# Пилотный эксперимент: раскрытие LIMO_2106

## Цель и статус

Сравнить, помогает ли рост контроля референсов удержать идентичность автомобиля и пространственную непрерывность при десятисекундном раскрытии жёлтого лимузина ВАЗ-2106. План: 240 кадров при 24 fps; неизменная геометрия одной машины, камера начинает с классического передка и постепенно раскрывает удлинённый кузов. Физический левый борт — `-X`, правый — `+X`, при направлении вперёд `+Y`. Это прокси-контракт, не утверждённый ассет и не готовый render.

Утверждённые character sheets, модель автомобиля, keyframes и Blender-видео сейчас отсутствуют в этом пакете. Соответствующие варианты нельзя считать исполнимыми для provider до подтверждения ассетов через существующий реестр GremoVOD и approval workflow. Генерации не выполнялись.

Суммы $1.50 и $2.25 — **оценки локального каталога для сравнения**, не quote от текущего provider и не гарантия цены. Для конкретного payload стоимость должна повторно рассчитываться штатной quote-функцией перед GenerationReview. Сумма фактического расхода остаётся `null`, поскольку запусков нет. Не запускать и не повторять платные запросы в рамках этого исследования.

## План метрик после разрешённого пилота

- Нарушения неизменности геометрии: изменение длины/колёсной базы, деформация панелей или morph — целевой результат 0.
- Ошибки канона передка и сторон: BMW-подобная решётка, неверное количество дверей/окон, перепутанный физический борт — целевой результат 0.
- Непрерывность reveal: полная длина появляется из движения камеры, без изменения объекта.
- Технические показатели: файл читается, разрешение/кадровая частота/длительность соответствуют выбранным параметрам, проверка ffprobe проходит.
- Стоимость принятого клипа = подтверждённые фактические расходы / число клипов, прошедших технический и ручной художественный просмотр. Для текущего пакета метрика не рассчитана.

## Гейты и ручная приёмка

1. Остановить подготовку к запуску, если любое изображение не имеет существующих `asset_id`, утверждённой версии и SHA-256 или роль/slot mapping не совпадает с фактическим provider payload.
2. Заблокировать оплату при неизвестной оценке, отсутствии explicit approval либо неясном состоянии предыдущей попытки.
3. `PASS_TECHNICAL` фиксирует только свойства файла. Отдельный человек должен оценить ВАЗ-2106 передок, 4 колеса, двери/вставку/узкие окна, физический борт, длину, отсутствие morph, reveal камерой и монтажную непрерывность.
4. Художественное `APPROVED` не выводится из статуса завершения provider или из прохождения технического probe.
5. Переход C заблокировать до подтверждения безопасного Blender preview и реальной поддержки video reference маршрутом адаптера.

Текущий статус: **DRY-RUN DESIGN ONLY**. Для B/C references являются незаполненными/неутверждёнными. Blender PoC — `BLOCKED_ENV`; возможности передачи video reference — `BLOCKED_PROVIDER_PATH`, пока не подтверждены аудитом реального адаптера и фактического wire payload.
