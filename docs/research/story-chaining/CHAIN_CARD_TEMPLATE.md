## Проверка перед публикацией
- [ ] Каждая короткая история понятна и смешна сама по себе.
- [ ] Не потеряна развязка собственного конфликта, нет искусственного «часть 2».
- [ ] Три темы реально различаются; вопросы вытекают из просмотренного.
- [ ] Следующие ролики **существуют и опубликованы** либо сцепка отложена.
- [ ] Название и переход соответствуют вопросу.
- [ ] Сцены и поведение соответствуют утверждённой версии канона.
- [ ] Режиссёрские секреты (в том числе reveal лимузина) не спойлерятся заранее.
- [ ] Для 9:16 отдельно проверена читаемость лиц, реквизита, плашек.
- [ ] Версия самостоятельного финала сохранена; сцепка — новая версия, без overwrite.
- [ ] Пользователь одобрил сценарный вариант и публикацию.
