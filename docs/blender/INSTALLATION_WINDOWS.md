# Установка и запуск на Windows

Это инструкция для подготовки Windows-среды после прохождения G1. В текущем хосте G1 заблокирован: не запускать Blender-сцену, builder или render benchmark, пока владелец не предоставит изолированную одноразовую VM/учётную запись без секретов и не сохранит isolation receipt. Offline `benchmark_render.py` лишь записывает JSON NOT_MEASURED и допустим без Blender. Receipt сам по себе не открывает запуск: isolated launcher с ограничениями доступа и ресурсов ещё не реализован. Обычный subprocess с очищенными переменными не удовлетворяет этому требованию. Инструкция не устанавливает Blender, не включает MCP и не меняет пользовательские файлы.

## Предварительные условия

1. Проверить Blender executable и версию:

   ```powershell
   $Blender = 'C:\AI_Workflow_Studio\tools\blender\blender-4.5.15-windows-x64\blender.exe'
   & $Blender --version
   ```

2. Проверить FFmpeg и ffprobe 9.0.2 в пользовательской установке, не выводя секреты и содержимое `.env`.
3. Подготовить отдельные `runtime`, `TEMP` и config каталоги внутри тестового worktree. Не использовать рабочую базу студии или продукционные `.blend`.
4. До запуска проверить isolation receipt и его соответствие актуальному хосту; зафиксировать receipt в отчёте прогона. Без него остановиться. После разблокировки входная сцена должна быть создана reviewed builder и помечена `NON_CANONICAL_PROXY`. Утверждённой модели ВАЗ в комплекте пилота нет.

## Безопасный профиль CLI

Только после подтверждения G1 запускать отдельный процесс Blender с очищенным набором переменных окружения, отдельными `HOME`/`USERPROFILE`-совместимыми настройками и TEMP, `--factory-startup`, `--disable-autoexec`, фиксированными скриптом и аргументами. Установить таймаут и предел места для попытки; остановить запуск при непредвиденном файле/процессе или ошибке. В лог писать версию и измеренные длительности, скрывая значения окружения. Эти параметры являются дополнительными мерами внутри VM/учётной записи, а не заменой изоляции.

Даже с этими настройками Blender внутри разрешённой изолированной среды не должен открывать случайные `.blend`, исполнять LLM-generated Python, получать токены или включать live MCP. Для недоверенных файлов нужна отдельная одноразовая VM/учётная запись без учётных данных.

## Проверка результата

Сначала выполнить preflight геометрии и диагностический кадр. Затем создать кадры 16:9 и 9:16 из одного неизменного master, проверить первый/средний/последний кадры, хеши master до/после, декодируемость и размеры через локальные инструменты. Сохранять логи, manifest и отчёт QC рядом с результатом в runtime. Успешное открытие Blender не доказывает рендер; успешный рендер не доказывает каноничность модели или визуальное принятие. До owner review все результаты остаются `PENDING_HUMAN_REVIEW`.
