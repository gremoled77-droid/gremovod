## 2. Решения владельца (не переигрывать без вопроса)

1. **Название:** ГремоВОД (рус.) / GremoVOD (лат.). «Гремовод», «Гримавод» — опечатки голосового ввода. Код и папки не переименовывать.
2. **v2** — новая оболочка в одном окне поверх прежнего сервера и базы; переписывать сервер не нужно. Мобильная версия — позже.
3. **Структура:** фото → шот (видео 4–6 с из одного фото) → кадр (6–12 с, черновая склейка шотов в студии) → сцена → серия → сериал. **«Кадр» — только структурная часть сцены**; содержимое картинки — «на фото / в шоте»; если неясно — переспросить.
4. **Студия общая для разных проектов:** всё специфичное — в паспорте проекта с режимами («3D-мульт», «реалистичное кино»).
5. **Стиль ГремоВОДа ещё не выбран** — владелец сделает пробы и выберет эталон. Палитра «баклажан, янтарь, ночной Минск» отменена. По умолчанию день; ночь, зима — варианты места; утро, вечер, дождь — словами.
6. **Пакет героя — 8 ракурсов, обязателен.** Образы — подпапки героя из основного пакета («только одежда» по умолчанию, «меняет внешность»; «+ Свой образ»). Машину владелец моделирует в Blender — она отдельный герой с пакетом.
7. **Реальные фото** — скрытая папка `Real Reference`, в интерфейсе не видны, пока не используются.
8. **Подтверждение платного запуска** — только Seedream 5 Pro и шот дороже $0.50. LLM, остальные фото и дешёвое видео — без подтверждения. Главная защита — не отправлять такой же запрос, пока предыдущий без ответа; другая модель — сразу.
9. **Промпт:** кнопки дают отработанные английские фразы → LLM переписывает под модель → русская сводка, английский по нажатию.
10. **«Допилить»** — скрытая кнопка на фото, чек-лист «Что не так?» (свет, камера, глубина, атмосфера, стиль и лицо, «Очистить» — тексты владельца от шума и фрактальности), режимы «Исправить этот» / «Новый шот из этого».
11. **Монтаж** финальный — CapCut/DaVinci; студия собирает кадры черново и выгружает дорожки. Апскейл — необязательная кнопка. Липсинк — позже (модели с аудио-входом).
12. **Помощники-LLM по уровням** — после визуала: разложить скиллы по уровням и экранам, у каждого уровня свои «законы».
