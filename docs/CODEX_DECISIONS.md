## Неизменяемые границы

- Не применять миграцию к настоящему `studio.sqlite3`, пока не проверены бэкап, рабочая схема, права доступа и процедура отката.
- Не тратить реальные кредиты на TTS, image, video, lip-sync, A8 и иные платные провайдеры: нужен подтверждённый API, доступный лимит, модель/цена и явная авторизация **конкретного запроса**, которую должен обеспечивать защищённый runtime FastAPI.
- Не импортировать автоматически новые свойства персонажей, цветов, голосов или локаций как канон. Не публиковать сериал или workflow.
- Нет настоящего пользовательского MP4: реальные способности video/audio QA и художественный `READY` остаются BLOCKED. Синтетический mock MP4 можно генерировать локально из FFmpeg, но такой тест подтверждает только техническую часть.
- Изоляция: n8n Cloud не имеет прямого доступа к Windows loopback; только outbox/pull-outbound с авторизацией и подписью после отдельного threat review.
- Рабочий проект `main` и черновой PR #17 не объединять автоматически. Все результаты — в новой ветке `feature/p0-studio-foundation-20261019`.

## Шесть этапов и критерии честного статуса

1. **Память и деньги**: schema + migration dry-run+backup + SQLite/JS аварийные тесты + спецификация 7 WF. Переход автоматический после GREEN CI, но production migration остаётся неисполненной.
2. **Приёмная комиссия**: локальный `ffprobe` на синтетическом видео, evidence manifests, zero-LLM N34, три reviewer MOCK со статусом BLOCKED. Real video acceptance остаётся отложенной.
3. **Сценарная комната**: N01–11 mock, skills registry, owner gates, approval freeze; реальные LLM вызовы отключены.
4. **Вся труба на mock**: 7 modular WF draft + synthetic media factory + manifest gate + ffmpeg join + repair only shot_02 cache reuse. Без платных вызовов.
5. **Боевые провайдеры**: только абстракции Kie/TTS/image/video, strict authorization and feature flags default OFF; живые платные тесты требуют проверяемой безопасной авторизации.
6. **Пилот**: mock end-to-end (3–5 slots) + QA handoff. Настоящий мультсериал с голосами и персонажами — отдельный BLOCKED milestone до наличия медиа и реальных approved канонов.

**Не считать зелёный mock исполнением реального production.** Промежуточные отчёты и blockers — в GitHub. Продолжаем шаги автоматически без диалога с владельцем.
