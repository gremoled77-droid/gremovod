# Qwen Image 2.1 — короткий гайд по промптам

Честно: надёжных материалов мало. `qwen21-model.txt` и `qwen3-model.txt` в репозитории пустые (4 байта, слово «Qwen»). Есть только `qwen-edit-guide.txt` (Alibaba Model Studio) и каталог PiAPI. Для студии это простая быстрая модель для черновых фото: простые слова работают лучше всего.

## 1. Модель и лимиты
- PiAPI: `Qubico/qwen-image-2.1` (Turbo), только `txt2img`, без референсов и правок, 1 картинка за запрос, $0.015. [docs/PIAPI_MODELS_2026-10-16.md; model_catalog.py]
- Поля: prompt, width/height 64–4096, произведение не больше 1 763 584 px (1328×1328 проходит, 4096×4096 нет), steps 1–16 (рекомендовано 8), seed. [PIAPI_MODELS; model_catalog.py]
- `negative_prompt` и `flow_shift` Turbo игнорирует: ненужное описывать прямо в промпте. [PIAPI_MODELS; qwen-edit-guide.txt]
- Официально у Alibaba (не PiAPI): размер 512×512…2048×2048, пропорции от 1:8 до 8:1, до 10 референсов, `prompt_extend` включён по умолчанию (для коротких промптов оставить, для подробных выключить), есть прозрачный фон. [qwen-edit-guide.txt; Alibaba Model Studio docs]
- Правки и референсы через PiAPI идут только старой моделью `Qubico/qwen-image` image-edit (image1–image3, $0.025), не 2.1. [PIAPI_MODELS]

## 2. Как писать промпт
- Достаточно простых слов: кто, где, что делает, стиль. Официального гайда по длине для 2.1 нет. [не найдено в официальных источниках]
- Если нужно прибавить деталей, коротко опиши свет, материал, настроение. Сторонние гайды говорят, что подробнее обычно лучше (до ~1000 токенов у семейства), но для Turbo это не проверено. [неофициально: https://wavespeed.ai/blog/posts/blog-how-to-use-qwen-image-2-0-text-to-image-editing/]
- Один кадр = одна сцена, один главный объект.

## 3. Свет, камера, мм
- Официальных требований к техническим терминам нет. Сторонний гайд упоминает объектив (wide-angle, 50mm), направление света, golden hour, текстуры («wet moss», «worn fabric»). [неофициально: wavespeed, URL выше]
- Практика для студии: достаточно слов «soft window light», «low angle», «close-up», «wide shot», без цифр диафрагмы. Проверить тестом.

## 4. Референсы и правки
- 2.1 в PiAPI без референсов, для них брать другую модель. [PIAPI_MODELS]
- В правках (Alibaba) картинки нумеруются по порядку: «image 1», «image 2» или «[image 1]»; лучше входные изображения 384–3072 px. Пример типа «Place the alarm clock from image 1 next to the vase in image 2». [qwen-edit-guide.txt]
- Для сохранения лица в правках официальный пример прямо пишет «perfectly preserve the facial features». [qwen-edit-guide.txt]

## 5. Текст на картинке
- Официальная документация даёт примеры правки текста (замена слов, шрифт, цвет), но не обещает точность для 2.1. [qwen-edit-guide.txt]
- Сторонние гайды: текст в кавычках, рядом шрифт («bold sans-serif»), место («centered at top»), короткие строки до 6–8 слов, сильны китайский и английский. [неофициально: https://wavespeed.ai/blog/posts/qwen-image-2512-text-rendering/ и https://wavespeed.ai/blog/posts/blog-how-to-use-qwen-image-2-0-text-to-image-editing/]
- Автор skill-репозитория: при сбое помогают фиксированный seed и замена слова; кириллицу/иероглифы проверять глазами. [неофициально: https://github.com/dseditor/qwen-image-21-prompting]

## 6. Ошибки
- Писать negative prompt для Turbo (игнорируется). [PIAPI_MODELS]
- Ждать референсы от 2.1 через PiAPI. [PIAPI_MODELS]
- Ставить размер выше лимита по пикселям (4096×4096). [PIAPI_MODELS]
- Длинный абзац текста на картинке: короткие слова надёжнее. [неофициально: wavespeed]
- Прозрачность чистая для предметов, но портит текст. [неофициально: dseditor]

## 8. Неизвестно, проверить тестом
- Влияет ли длина промпта на Turbo при 8 шагах. [не проверено]
- Точность кириллицы в тексте. [не проверено]
- Есть ли выигрыш от 12–16 шагов вместо 8. [не проверено]
- Работает ли «camera/мм» лексика заметно. [не проверено]
- Формат ответа (`image_url`/`image_urls`). [PIAPI_MODELS]
