# Гайды по промптам моделей (черновики, 24.10.2026)

Собраны агентами из официальных документов, скачанных в `docs/official-prompts/`, и из сети (блоги, GitHub; Reddit для агентов был закрыт). Всё неофициальное помечено «неофициально» со ссылкой. **Вживую ничего не проверено**; в конце каждого файла список того, что проверить тестом (платные тесты — только с разрешения владельца, до $1).

| Файл | Модель | Главное |
|---|---|---|
| `nano-banana-2.1.md` | Nano Banana 2.1 | официально до 14 референсов; через PiAPI 5 форматов, 1K/2K/4K, до 10 референсов; структура «референсы + связь + новая сцена» |
| `seedream-5.md` | Seedream 5 Pro и Lite | связный естественный язык, не список слов; роли референсов; Pro 1K/2K $0.068/$0.136, Lite 2K/3K $0.052 |
| `qwen-image-2.1.md` | Qwen Image 2.1 (Turbo) | через PiAPI только текст в картинку, без референсов и правок, $0.015; простые слова |
| (в `docs/master-prompts/`) | GPT Image 2.5 | `photo-gpt-image-2.5.md`, источник — книга `GPT-Image-2.5-promptbook.pdf` |
