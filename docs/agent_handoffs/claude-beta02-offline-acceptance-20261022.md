## Одна команда

```
python tools/beta_offline_acceptance.py --quick     # адресные проверки (около минуты)
python tools/beta_offline_acceptance.py --full      # плюс весь backend pytest (около 2,5 минут)
python tools/beta_offline_acceptance.py --quick --fault b1|owner|ledger   # самопроверка: сломанный продукт обязан дать FAIL (код 1)
python tools/beta02_candidate.py --dest <папка вне репозитория>           # одноразовая интеграционная копия по закреплённым SHA
```

Нужны python с зависимостями `backend/requirements.lock.txt` и pytest, ffmpeg и ffprobe (без них шаги BLOCKED, автоустановки нет).
Код выхода: 0 — все обязательные шаги PASS; 1 — есть FAIL; 2 — есть BLOCKED или NOT_RUN. Отчёты `report.json` и `report.md` пишутся во временную папку или в `--out`.
`unpaid_calls: 0` пишется только при PASS всех обязательных шагов и нуле сетевых попыток по ловушке `tools/beta02_tripwire.py` (loopback разрешён, любой другой DNS или connect — ошибка и запись в отчёт).
Данные: временный `STUDIO_DATA_DIR`; реальные файлы ключей изолированы патчами; ролики собирает локальный ffmpeg.

## Что покрыто независимо от `test_release_gate.py` (`tests/test_beta02_integration.py`)

- Контракт HTTP и схема `/gate`.
- Полный путь: отказ без QC, N34, N35, утверждение точного SHA, перезапуск приложения над той же SQLite.
- Перезапуск после изменения байтов и новая проверка: решение по старым байтам не воскресает, в истории 2 записи.
- Резервная копия SQLite (online backup) и копия библиотеки: решение сохраняется, `PRAGMA quick_check` даёт ok; восстановление без файла утверждением не считается.
- Повторный QC не меняет хеш и решение.
- Действия выпуска не меняют регистр денег и не вызывают провайдера.
- Матрица fail-closed: неверный и пустой SHA, чужой владелец, нет прав на обработку, владелец не настроен, 409 при старой ревизии импорта.
- Машинный токен: 403 с сессией, 401 без неё; изменение байтов после QC; пропавший файл; 5 параллельных одинаковых утверждений дают одну запись; отказ без QC и без файла.
- GA-01 рядом с выпуском: нечитаемая сумма блокирует траты проекта до и после перезапуска, `/api/budgets` отвечает 200, `costs_complete = false`, провайдер не вызван, бесплатный выпуск продолжает работать; старая запись другого проекта его не блокирует.
