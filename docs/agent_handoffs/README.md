# Handoff агентов — отдельные короткие отчёты без конфликтов

Каждый агент обновляет **только свой** файл `docs/agent_handoffs/<роль>-<задача>.md` в своей ветке; `STATUS.md` обновляет назначенный координатор.

Шаблон для новых файлов:

```markdown
# <роль> — <ID задачи>
- Сделано: <что действительно выполнено>
- Файлы: <точные пути + commit SHA>
- Следующий шаг: <кому и что делать, ссылка на PR>
- Проверки: <команда, статус, ссылку на CI, не путать MOCK с production>
- Блокировки для Codex: <ID из CODEX_DECISIONS.md или «нет»>
```

Ничего не объявлять выполненным без фактического теста. Нельзя выводить ключи API/полные приватные файлы/данные персонажей.
