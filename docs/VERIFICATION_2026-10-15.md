# Проверка и продолжение AI Workflow Studio — 15 октября 2026

Прочитаны файл передачи контекста и TECHNICAL_SPEC.md. Разработка продолжена в существующих frontend/ и backend/. Приложение не переписывалось; другие проекты в соседних папках не изменялись.

## Исправления

- Воспроизведены TS2604 и TS2786. ReactFlow импортируется именованно из установленного @xyflow/react; CSS уже был подключён и не продублирован.
- Для единственного TypeScript-проекта build использует `tsc --noEmit`, затем Vite. Это сохраняет проверку типов и устраняет необходимость записи tsconfig.tsbuildinfo, которая завершалась EPERM.
- Добавлен ErrorBoundary с сообщением об ошибке и кнопкой перезагрузки. Несохранённые изменения при перезагрузке теряются — это явно указано на экране.
- Статус backend запрашивается через /api/health, есть кнопка повторной проверки. Ошибки обновления проектов/очереди больше не подавляются молча. Общая функция fetch используется в App и AgentPanel; для health таймаут 10 секунд, для остальных запросов — 180 секунд.
- Исправлена утечка SQLite-соединений: контекст гарантирует commit/rollback и close. До исправления интеграционные тесты выявляли удержание файла БД в Windows.
- Добавлен /api/prompt-drafts и кнопки локального черновика в Image Lab / Video Lab. Черновик использует задание, канон персонажа, профиль именно выбранной модели и Style Bible. Это шаблонная сборка текста для ручного редактирования, без LLM и внешних запросов.
- AgentPanel получает Style Bible текущего проекта вместо отдельного жёстко заданного канона; дополнительные замечания передаются отдельно. Внешний запуск агентов не выполнялся.
- Список файлов персонажа очищается при переключении проекта/персонажа, чтобы не показывать файлы предыдущего выбора.

## Проверено

`npm install` завершился успешно, аудит сообщил 0 уязвимостей на момент установки. `npm run build` проходит. Vite выдаёт неблокирующее предупреждение об игнорировании `use client` в @xyflow/react.

В настоящем браузере открыт http://127.0.0.1:5173/. Видны интерфейс и статус backend. Проверены переключения студии, графа с тремя узлами и связями, библиотеки стиля и агентов. Локальный черновик появился в поле промпта и содержал стиль проекта. В журнале консоли основной страницы при этой проверке нет warn/error.

Отдельная dev-страница http://127.0.0.1:5173/smoke/error-boundary.html намеренно выбрасывает SMOKE_TEST_RENDER_FAILURE. В браузере отображается экран восстановления вместо пустой страницы. Fixture не входит в production bundle; консольные ошибки на этой странице ожидаемы.

Пять интеграционных тестов прошли:

1. Health и диагностика.
2. Создание, чтение, обновление проекта; сохранение/повторное чтение персонажа, изолированных модельных профилей, стиля, графа, отдельных промптов и video reference; удаление персонажа/стиля из состояния через сохранение. Отдельного DELETE проекта в API сейчас нет.
3. Загрузка, чтение и удаление файлов во всех четырёх категориях референсов, отклонение неизвестной категории. Тест проверяет хранение байтов, а не визуальную корректность изображения.
4. Локальные черновики: канон, стиль, изоляция модельного профиля и неизвестная модель.
5. Отклонение ряда некорректных параметров и референсов до внешнего вызова.

Тесты используют временные БД и каталоги. Внешние вызовы заменены заглушками, которые падают при попытке обращения. Пользовательские проекты тестами не изменяются.

На работающем сервере через Vite proxy проверены ответы 200 для /api/health, /api/model-specs, /api/projects, /api/jobs, /api/diagnostics и POST /api/prompt-drafts. Старый backend перезапущен, актуальный backend слушает 127.0.0.1:8000; Vite — 127.0.0.1:5173.
