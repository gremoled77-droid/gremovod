# Автоматизация промпта и Seedance — 15 октября 2026

## Что изменилось

Кнопка «Подготовить промпт через API» теперь сохраняет актуальное состояние проекта и открывает предпросмотр контекста. Backend получает из проекта задание, motionBrief, библию мира, выбранного персонажа, только его профиль для целевой модели, параметры и упорядоченные референсы. Если выбрана картинка из библиотеки, добавляются её метаданные и исходный промпт. Это описание референса из метаданных, а не визуальный анализ пикселей.

В backend/prompt_rules.py добавлены версионируемые инструкции 2026-10-15.1, адаптированные из ai-video BRIEF и cinematic-studio motion/provider guidance. Внешняя LLM получает текст этих правил; она не имеет доступа к локальному каталогу навыков. Контекст проекта трактуется как данные, канон персонажа и локации сохраняется, чужие модельные профили исключаются. Для Seedance используются реальные @imageN в порядке массива; видео- и аудиореференсы этим адаптером не принимаются.

POST /api/compose/preview не вызывает внешних API. POST /api/compose требует approved=true и выполняет один LLM-запрос через существующий PiAPI/OpenAI транспорт. Ответ ограничен существующим max_output_tokens=1400. Перед отправкой пользователь видит, что запрос платный; точная долларовая оценка LLM пока не реализована и это указано в UI. В этой проверке реальный LLM-запрос не запускался.

Непустой результат с корректными индексами референсов сохраняется в SQLite prompt_versions вместе с контекстом, выбранной LLM, usage и версией правил. Текущий промпт целевой модели обновляется отдельно, без перезаписи промптов других моделей. GET /api/projects/{id}/prompt-versions возвращает историю; отдельная полноценная панель истории в UI пока не добавлена. UI применяет полученный текст в редактируемое поле. Медиа не запускаются автоматически.

## Video Lab

Seedance 2.5 включён в общий API заявок с подтверждением стоимости и защитой от повторной отправки. Проверяются целочисленная длительность 4–30 секунд, разрешение 480p/720p/1080p, формат кадра, лимит изображений и их индексы в промпте. Пакетные, draft, edit, extend, video/audio references в этом адаптере не открыты.

При наличии изображений backend задаёт mode=omni_reference и omni_reference_task_type=reference; без изображений — text_to_video. Непроверенные generate_audio и дополнительные поля не отправляются.

Оценка считается по https://piapi.ai/docs/seedance-api/seedance-25: 480p — $0.15/сек, 720p — $0.35/сек, 1080p — $0.80/сек. Для выбранных 480p и 5 секунд показано $0.75. Лимит сравнивается с локальной документированной оценкой; фактический биллинг определяется PiAPI. Прежний бюджет $0.06 для тестового изображения не покрывает видео.

Задание сохраняется до отправки. Используются существующие очередь, ручная проверка task_id, idempotency и статус неопределённого исхода без автоматической повторной оплаты. Готовое видео можно сохранить из очереди через /api/jobs/{id}/outputs/{index}/save: скачивание ограничено 200 МБ, ffprobe проверяет MP4/MOV и видеодорожку. Оригинал и параметры сохраняются в общей библиотеке; UI показывает video player и скачивание. Изображения продолжают использовать существующий путь сохранения.

## Проверки и ограничения

- Сборка frontend проходит.
- 19 тестов проходят; pip check не находит конфликтов.
- Тестами проверены контекст и правила, изоляция профилей, история и usage, выдуманные индексы, цены Seedance, недостаточный лимит, отсутствие подтверждения, формат payload, защита от дубля и сохранение настоящего синтетического MP4 с повторным открытием.
- Внешние LLM и видеоответы в тестах заменены заглушками. Поэтому успешный реальный запрос GPT/Seedance этой проверкой не подтверждён.
- В браузере проверены предпросмотр LLM и окно Seedance с $0.750, одним изображением и 5 секундами. Платные кнопки оставлены без согласия, отправки не было.
- Проверены бесплатные preview/estimate на настоящем сохранённом проекте. Количество реальных медиа-задач проекта осталось равным одному — ранее разрешённый тест Seedream.
- Скриншоты: prompt-api-review.png, seedance-api-review.png.

Пока не реализованы автоматический polling в фоне, загрузка истёкшего референса в облачное хранилище провайдера, общий бюджет проекта и долларовая оценка LLM. Поле движения можно редактировать отдельно от исходного задания изображения. Качество будущего промпта и видео нужно оценить на отдельно разрешённом реальном запуске.
