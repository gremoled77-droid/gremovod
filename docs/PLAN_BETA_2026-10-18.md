# План до беты — 18.10.2026

Цель беты: человек заходит → открывает «Гремолед» или создаёт новый проект → записывает идею → генерирует → правит мир → отправляет кадры на генерацию. Всё в одном дизайне, без лишних экранов, с понятными клавишами.

## Что делаем — по порядку

Каждый шаг — отдельная небольшая ветка, проверка в браузере, слияние в main. Новых функций до беты не добавляем.

### Шаг 0. Процесс (полдня)
- Бэкенд в разработке — с автоперезапуском (`uvicorn --reload` в `scripts/start_studio.py` под флагом `--dev`).
- HANDOFF: сжать до одной страницы «как сейчас устроено + 5 правил»; историю перенести в `docs/archive/`. TODO: оставить только этот план и список «после беты».
- Разделить зоны: пока идёт чистка, App.tsx и навигацию правит только один агент.

### Шаг 1. Чистка (1–2 дня)
- Навигация беты: **Старт · Идея · Мир (с героями) · Раскадровка · Кадры · Видео · Узлы**, внизу Настройки. Звук, Монтаж, Выпуск — пока скрыть (одна строка «скоро» на Старте).
- Убрать из навигации и из сборки: «Сцена», «Допилить», «Агенты», `StoryboardDemo`, старый `ChatGPTPanel`; мобильные вкладки свести к тем же этапам. Код не удалять сразу — перенести в `frontend/src/legacy/` и выключить, удалить после беты.
- Разрезать `App.tsx`: таблица экранов `screens.ts` (`{mode, title, component}`) + маленький `App.tsx` (каркас, проект, переключение). Каждый экран получает пропсы, а не лезет в App.
- `style.css` подключать только к экранам из `legacy/`.

### Шаг 2. Единая кнопка генерации картинок (2 дня) — главный приоритет
- Один хук `useImageGeneration()` + один компонент `GenerateButton`: кнопка «Сгенерировать · $цена» и рядом стрелка ▾ с выбором способа:
  - **API (PiAPI)** — по умолчанию, через `GenerationReview` и токен подтверждения (как сейчас, не обходить);
  - **ChatGPT вручную** — копирует промпт и референсы, открывает чат, ставит задание «ждём картинку»; возврат — вставкой (Ctrl+V), перетаскиванием или из галереи телефона;
  - **Codex** — очередь `/api/chatgpt/jobs`; если ветка не слушает — честно писать «Codex не подключён» и предлагать ChatGPT.
- Выбор способа запоминается для проекта. Эта же кнопка во всех местах: Кадры, герои/Мир, локации, узел «Изображение», «Редактировать» на Старте.
- Один общий «лоток ожидания» (что ждём из ChatGPT/Codex) в правой панели `Dock`, а не в каждом экране свой.
- Готово, когда: из любого места картинка запускается одной кнопкой, приходит в библиотеку и видна в очереди; все 7 ручных вызовов очереди заменены хуком.

### Шаг 3. Клавиши (1 день)
Один файл `hotkeys.ts` + подсказка по `?`. Не срабатывают, пока курсор в поле ввода (кроме Ctrl+Enter, Esc, Ctrl+V).

| Клавиша | Действие |
|---|---|
| Ctrl+Enter | Сгенерировать (всё равно откроется окно цены) |
| Esc | Закрыть окно / снять выбор |
| Ctrl+K | Быстрый поиск: экран, проект, кадр, герой |
| Alt+1…7 | Перейти к этапу |
| / | Курсор в строку промпта |
| Ctrl+V | Вставить картинку как референс или как ответ ChatGPT |
| ← → | Листать кадры; F — в избранное; Del — в корзину с «Отменить» на 10 с |
| Ctrl+Z | Отменить последнее «в корзину» |
| ? | Показать все клавиши |

Без звуков и всплывающих подсказок при каждом нажатии; подсказка клавиши — только в `title` кнопки.

### Шаг 5. Единый дизайн оставшихся экранов (по 1 дню на экран)
Порядок: **Идея → Мир (с героями и локациями) → Узлы (доделать мобильную) → Видео**. Шаблон один: шапка экрана, рабочая область, правая панель параметров/моделей, снизу строка промпта с `GenerateButton`. Новые экраны — без `style.css`.
