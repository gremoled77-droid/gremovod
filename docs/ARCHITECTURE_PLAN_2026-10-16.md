# План наведения порядка и развития (16.10.2026)

Решения владельца: один пользователь; нужен доступ из облака (с телефона), ключи уже внесены; сначала только API (нативный imagegen Codex остаётся необязательным режимом); первые модели: GPT Image 2.5, GPT Image 2.0, Nano Banana 2.1, Seedream 5.0 Pro, Seedream 5.0 Fast, Qwen 2.1.

## Этапы
1. Гигиена: git, чистка, version/README, вынос каталога моделей, разбиение main.py и App.tsx. (в работе)
2. Единый движок: интерфейс адаптеров (submit/poll/fetch/price), одна очередь в SQLite, SSE вместо таймеров, перенос KIE-адаптеров из model-studio.
3. Экран «Создать» в стиле Higgsfield: референсы, промпт, модель, пресеты, цена до запуска.
4. Доска сцен/кадров: участники, дубли, главный дубль.
5. Видео: «Оживить» из кадра, камеры, дешёвая связка + апскейл.
6. Облако: PostgreSQL/объектное хранилище или один VPS с SQLite+диск, авторизация, HTTPS, секреты в хранилище, PWA для телефона.

## Решение 16.10.2026: провайдеры и ручной маршрут
- Основной провайдер генераций — **PiAPI** (все шесть моделей приоритетно через него; KIE из model-studio — не основной путь, адаптеры переносим только если PiAPI не покрывает модель).
- Нужен **ручной маршрут «Внешняя генерация»** (ChatGPT / GPT Image и другие сайты без API): кнопка «Скопировать промпт» → пользователь генерирует снаружи → возвращает готовую картинку в софт (загрузка файла, Ctrl+V из буфера, перетаскивание; с телефона — «Поделиться/выбрать фото»).

### Что уже есть
- `/api/library/import-image` — загрузка изображения в библиотеку (PNG/JPEG/WebP, до 20 МБ, SHA256, provider=`local_import`).
- Канал `/api/chatgpt/*` — но он зависит от открытого чата-исполнителя Codex (необязательный режим).

### Чего не хватает (реализовать)
1. Загрузка привязывается к **задаче внешней генерации**, а не «висит» в библиотеке: `external_job` (project_id, shot/node_id, target-модель, текст промпта, версия промпта, референсы, статус `waiting_external → received`).
2. Результат пишется как **попытка кадра** с provider=`external:<сервис>`, ссылкой на промпт и модель; оригинал не перезаписывается.
3. Учёт в экономике: ручная попытка = $0 по API, но с пометкой «эквивалент по API» и подпиской/сервисом.
4. Карточка кадра: кнопки «Скопировать промпт», «Вставить результат», история внешних попыток рядом с API-дублями; можно выбрать любой дубль главным.
5. Кнопка «Копировать» собирает полный промпт: текст + нумерованный список референсов («Image 1 — …») и список файлов, которые нужно приложить в ChatGPT (можно скачать пакетом).
6. Работа с телефона: загрузка из галереи, вставка из буфера; без зависимости от Codex.

## Решения 16.10.2026: воркфлоу и временные результаты

- Результаты узлов попадают в «Темп» и удаляются через 7 дней, если не использованы; сердечко переносит результат в постоянное хранение.
- «Запустить всё» — только с подтверждением цены; детали параметра уточнит владелец позже (см. TODO.md).
