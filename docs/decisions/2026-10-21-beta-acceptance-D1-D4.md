# GremoVOD — утверждённые решения владельца D1–D4

**Дата:** 2026-10-21  
**Статус:** OWNER_APPROVED — решения о границах первой беты; **не** одобрение кода, платных вызовов или релиза.  
**Основание:** прямое решение владельца после [глобального аудита Codex, Draft PR #54](https://github.com/gremoled77-droid/gremovod/pull/54), [Decision Register](https://github.com/gremoled77-droid/gremovod/blob/audit/global-acceptance-20261021/docs/audits/global-acceptance-2026-10-21/07_DECISION_REGISTER.md).

| ID | Утверждённое решение | Последствие для исполнения |
|---|---|---|
| **D1** | **`mavis/work` — базовая ветка исправлений первой беты.** | Каждое исправление — отдельный task-branch/PR от зафиксированного актуального SHA `mavis/work`. `main` не меняется без независимой приёмки и согласования слияния. Это не автоматическое принятие всех коммитов из `mavis/work`. |
| **D2** | **Восстановить MiniMax Task API после GA-01.** | Сначала денежная безопасность **GA-01**; затем **GA-02** с полным тестом prepare → permit → execute, идемпотентности, аварий и UNKNOWN. До отдельной приёмки не считать Task API пригодным для реальных платных запросов. |
| **D3** | **Для первого пилота — локальный технический QC и ручное утверждение итогового MP4 владельцем.** | **GA-03:** разнести статусы `imported`, `technical_pass` и `owner_approved`, привязать QC и решение к **одному и тому же хешу файла/версии**. Не принимать импорт `ready` за разрешение выпуска. Обязательные три платных LLM-критика в первую бету не входят. Имеющийся N34/N35 использовать по фактическим контрактам, без создания второй системы QA. |
| **D4** | **Первый пилот — локальный производственный процесс с CapCut.** | CapCut — монтаж/рендер, GremoVOD — подготовка материалов, учёт, контроль и приёмка. **n8n Cloud не является блокером локального пилота**; интеграцию проверить отдельно позднее. Никакой автоматической публикации. |

## Что ещё не утверждено

- **D5 открыт:** владелец позже выбирает конкретный настоящий MP4 пилота и актуальный утверждённый snapshot канона/референсов для художественной и E2E-приёмки.
- **D6–D7 открыты:** роль/лимиты и сверка реальных расходов n8n, фактические GitHub branch protections/required checks — решения отдельно.
- Никаких реальных платных вызовов, API-ключей, миграций рабочей SQLite, развёртывания наружу, автослияния PR или утверждения художественного канона этим документом не разрешено.

## Исполнение и независимая приёмка

1. **MiniMax: GA-01 (P0)** — корректный LLM settlement; отсутствие/порча usage не должны превращаться в `$0` или отрицательную сумму. Отдельный Draft PR с офлайн-тестами. **Codex** принимает негативные кейсы из [плана повторных проверок #54](https://github.com/gremoled77-droid/gremovod/blob/audit/global-acceptance-20261021/docs/audits/global-acceptance-2026-10-21/08_ACCEPTANCE_AND_RETEST_PLAN.md).
2. **MiniMax: GA-02 (P1)** — восстановить Task API только после принятия GA-01; затем независимый retest Codex. Не открывать сломанный путь платным провайдерам.
3. **MiniMax: GA-03 (P1)** — статусы master/QC/owner по одинаковому хешу; Codex проверяет отрицательные сценарии и ручной browser path.
4. **MiniMax: GA-04 (P1)** — воспроизводимый офлайн CI в отдельном PR; **GA-05 (P1)** — доверенный прокси/throttling до любого удалённого доступа. Строгий порядок GA-02/03/04/05 уточняется зависимостями и безопасностью, не запускаются все задачи параллельно без согласования.
5. После приёмки нужных исправлений — один **изолированный MOCK E2E**, затем владелец предоставляет D5; проходит реальный локальный CapCut → MP4 → N34/N35 → ручная художественная/техническая приёмка с фиксацией хеша. Провайдерный paid smoke только по отдельному разрешению на конкретный запрос.

**Разделение ролей:** MiniMax пишет ограниченные исправления; Codex делает независимую приёмку; владелец утверждает интеграцию, деньги и финальный выпуск.

**Контрольная точка:** статус глобального аудита [#54](https://github.com/gremoled77-droid/gremovod/pull/54) остаётся **PARTIAL / NO GO для платной беты** до подтверждённого закрытия P0 и E2E; данное решение само статус не меняет.
