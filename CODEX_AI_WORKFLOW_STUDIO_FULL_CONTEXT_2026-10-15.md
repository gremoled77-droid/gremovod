## 2. Продуктовое видение

Собственная AI-студия для генерации мультсериалов, клипов и киношных сцен. Два режима с общей моделью данных:

- **Вертикальный редактор:** идея/сценарий/GPT → подготовка промптов под выбранные image-модели → генерации/галерея/выбор лучших изображений → video-модели с автоматически полученным референсным кадром → Audio Lab → библиотека/монтаж.
- **Node workflow:** визуальные блоки как Runway / ComfyUI (React Flow), соединения данных, ветвления и сравнительные генерации, очередь задач, повторный запуск отдельных узлов. Под каждым узлом и каждой моделью показывать только ПОДДЕРЖИВАЕМЫЕ типы входа: текст, изображения, multiple references, first/last frame, видео, аудио и т.п. Параметры подтверждать официальной документацией для конкретной версии модели.
- Источник правды — единый проект, набор сцен/шотов, идентификаторы ассетов, история промптов, model version, seed, настройки, стоимость и результат. Не хранить только плоскую историю сообщений.

## 3. Модуль промптов и API моделей

- GPT (собственный OpenAI API либо PiAPI) превращает свободное описание сцены в структурированный режиссёрский brief и **разные редактируемые промпты для каждой модели**.
- Нужны индивидуальные model adapters: точные task type, endpoint, payload schema, ограничения по входам, пропорциям, разрешению, качеству, duration, ref counts и ответам. Нельзя считать, что параметры одинаковы у GPT Image, Seedream, Nano Banana, Qwen, Midjourney, Wan, Kling, Seedance и других.
- Первые модели интереса: Seedream 5 Pro / 5 Lite, GPT Image 2, Nano Banana (проверять действующее название/версию 2.1 в API), Qwen Image 2.1, Midjourney (если доступно у действующего провайдера), Wan, Kling, Seedance; список расширяемый и основан на API-документации.
- Разделить LLM провайдеров и image/video провайдеров: OpenAI direct, PiAPI, позже другие.
- Прозрачное отображение статусов, ошибок, task ID, стоимости, сохранение оригинала и превью.

## 4. Консистентность персонажей и стиль мира

- **Character Vault:** каноническая карточка идентичности персонажа + **модельно-специфические карточки** (описание, порядок референсов, метод сохранения внешности, допустимое число картинок и ограничения). Избегать копирования одной и той же инструкции во все модели.
- Физические папки и метаданные для `real_references/`, `approved_generations/`, `failed_generations/`, `model_references/<provider_model>/`; хранить причины неудачи и версию генератора. Неудачные изображения использовать для анализа ошибок, но не смешивать автоматически с позитивными референсами.
- **Style Library / World Bible:** для проекта «Таксист Грэм» правила визуальной стилистики мира, окружения Минска, света, материалов, реквизита, костюмов, автомобилей, кадровой оптики; позитивные и негативные примеры. Связывать с персонажами и сценами.
- Важнейший герой «Грэм»: самоуверенный минский таксист на самодельном удлинённом трёхдверном ВАЗ-2106 цвета «баклажан», бренд GRAHAM VIP TRANSFER; интерьер: розочка на КПП, три иконки, болванчик, планшет на синей изоленте, персидский ковёр, кружевные занавески. Элементы закреплять референсами и каноном проекта, не переизобретать при генерации.
- Continuity Agent проверяет генерации и предлагает исправления без самовольного изменения канонических референсов.

## 5. AI-агенты и облако

- AI Director распределяет задачу, Prompt Agent адаптирует запросы, Continuity Agent следит за персонажами, Style Director за целостностью мира; далее Image, Video, Audio agents.
- Первый MVP агента — последовательная цепочка Director → Continuity → Prompt, сохраняющая структурированные результаты. Позже OpenAI Agents SDK, облачные workers и асинхронная очередь.
- Выбор OpenAI direct / PiAPI, но не хранить API-ключи в клиентском bundle, логах или репозитории. `.env`/серверные секреты.
- Платные операции: ручное подтверждение по умолчанию, лимит по бюджету, журнал затрат, retry только для временных ошибок.
- Local first (SQLite, локальные файлы), cloud later (PostgreSQL, object storage, queue, auth/roles).

## 6. Audio Lab

- Импорт локальных аудио/видео или разрешённых источников; извлечение звука, транскрипция, поиск пауз/фраз, выбор лучших дублей (пока с человеческим подтверждением), обрезка, шумоподавление, WAV, хранение и последующая отправка в ElevenLabs/Fish Audio.
- Не делать автоматическую загрузку с YouTube/Instagram в обход ограничений источников и без прав на материал.
- Для клонирования голоса — явно фиксировать согласие/права на использование.
- FFmpeg пока не найден на компьютере; обработка медиа не заработает до установки или настройки пути.

## 7. Поставщики API и выявленные проблемы

- Требуются интеграции: **OpenAI**, **PiAPI**, **ElevenLabs**, **Fish Audio**. Текущая стадия интеграции ElevenLabs/Fish — план/заготовки, не заявлять полноценную реализацию без тестирования.
- PiAPI GPT: пользователь дал пример `POST https://api.piapi.ai/v1/chat/completions` с заголовком `X-API-KEY` и `model: gpt-5.6-luna`. В Workspace PiAPI этот GPT отвечает успешно.
- Однако локальный сервер при запросах к `api.piapi.ai` получал **HTTP 403 Cloudflare Error 1010** / `browser_signature_banned`, `retryable:false`, `owner_action_required:true`, Ray IDs `a4ac02b7faff3d9d` и `a4ac08a43e2c70a4`. Не пытаться обходить защиту подменой сигнатур; обратиться к поддержке для разрешённого способа подключения. Прямой OpenAI API проектировать независимо.
- Ранние browser `Failed to fetch` / `non ISO-8859-1 code point` происходили из-за CORS/невалидных символов в заголовках; не смешивать с Cloudflare 1010.

## 11. САМОЕ НОВОЕ: реальная ошибка сборки React, полученная от пользователя

После выполнения `npm run build` в PowerShell (`PS C:\AI_Workflow_Studio\frontend>`) получены **две ошибки одной причины**:

```text
src/App.tsx:43:11785 - error TS2604: JSX element type 'ReactFlow' does not have any construct or call signatures.
src/App.tsx:43:11785 - error TS2786: 'ReactFlow' cannot be used as a JSX component.
Its type 'typeof import("C:/AI_Workflow_Studio/frontend/node_modules/@xyflow/react/dist/esm/index")' is not a valid JSX element type.
Found 2 errors.
```

Подтверждённая проблема в первой строке **существующего** `frontend/src/App.tsx`:

```tsx
import ReactFlow,{Background,Controls,MiniMap,addEdge,applyNodeChanges,applyEdgeChanges,Handle,Position,type Node,type Edge,type Connection,type NodeChange,type EdgeChange} from '@xyflow/react';
```

Для установленной версии пакета `@xyflow/react` (`^12.9.0`) вместо default import требуется **именованный** импорт `ReactFlow`. Исправить первую строку импорта на:

```tsx
import {
  ReactFlow,
  Background, Controls, MiniMap,
  addEdge, applyNodeChanges, applyEdgeChanges,
  Handle, Position,
  type Node, type Edge, type Connection, type NodeChange, type EdgeChange
} from '@xyflow/react';
```

Также проверить импорт CSS в `src/main.tsx` или `src/App.tsx`:

```tsx
import '@xyflow/react/dist/style.css';
```

Не добавлять дубль, если CSS уже импортирован. После изменения запустить в **PowerShell**:

```powershell
Set-Location C:\AI_Workflow_Studio\frontend
npm run build
npm run dev
```

В CMD смена каталога: `cd /d C:\AI_Workflow_Studio\frontend`, но в PowerShell **`cd /d` НЕ работает**: пользователь уже получил ошибку `Set-Location : Не удается найти позиционный параметр /d`.

**Статус:** исправление предложено, но пока пользователь НЕ подтвердил, что внёс правку и сборка стала успешной. Изменить исходники, собрать, открыть браузер и проверить результат — первоочередная задача Codex. Пустой экран предположительно вызван данным неправильным импортом, но окончательно это не проверено.

## 14. Правила безопасности, достоверности и работы

- Сначала факты проверок, затем заявления о готовности. Vite `ready` означает лишь запущенный dev-server, не успешный рендер интерфейса.
- Не пытаться исправлять CBS/DISM удалением WinSxS/CbsTemp или массовой выдачей прав. Windows 10 испытывает ошибки обслуживания, но Python/Node и серверы работают. Не делать восстановление ОС частью разработки приложения без явного запроса.
- OpenAI/PiAPI/ElevenLabs/Fish API-ключи не помещать в frontend bundle, localStorage, logs, репозиторий. Для локального MVP передача ключа может существовать, но переходить к серверным секретам.
- Не вызывать платные генерации автоматически до явного подтверждения и установки лимита расходов.
- Не маскировать, не обходить Cloudflare 1010; обращаться к PiAPI за разрешённой конфигурацией доступа.
- Никогда не автоматически использовать rejected generations как эталон персонажа.
- Поддерживать обратную совместимость проектов v0.2 и миграции схемы БД.
- Структура, тексты, модельные ограничения и точные названия моделей должны быть подтверждены актуальной документацией поставщиков. Приведённый в старых прототипах каталог и цены считать непроверенными без повторной сверки.
- Отчитываться на русском; исходники и зависимости документировать точно; каждый этап сопровождать командами тестов.
