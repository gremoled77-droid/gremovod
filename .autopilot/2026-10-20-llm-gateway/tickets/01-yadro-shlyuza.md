## Что должно заработать

Появляется серверный модуль, который по файлу конфигурации знает все маршруты и их тарифы и умеет считать **две разные величины** для одного и того же вызова:

- **тарифный ориентир** — сколько вызов стоил бы по тарифу Kie.ai или PiAPI, даже если выполнял его бесплатный маршрут;
- **фактическое списание** — сколько реально стоит вызов по тарифу того провайдера, который его выполнил.

Модуль ничего не знает про сеть и ничего не пишет в базу — это чистый расчёт и выбор маршрута. Он умеет выбрать маршрут по задаче и по режиму работы, зная, какие маршруты выключены, а какие бесплатны и требуют отдельного разрешения.

Пример файла конфигурации дополняется недостающими полями схемы: что умеет маршрут, какая у него роль, бесплатный ли он, какой upstream-идентификатор модели, какой потолок входа, сколько стоит кеш, есть ли токены размышления, какие лимиты.

## Из брифа, дословно

> «в карточках показываем стоимость по тарифам Kie/PiAPI даже для бесплатных вызовов»

> «Единый server-side model registry с датой/URL источника цены, проверкой поддерживаемых функций, enable/verified-флагами; никакие произвольные upstream URL/модели не приходят от пользователя.»

> «Если Kie.ai или PiAPI действительно продаёт ту же модель — сравнивать с её точным тарифом, пометка exact_model.»

> «Непроверенный тариф выводить как «Не подтверждён», а не $0.»

> «Бюджет: фактически +$0.00. Нельзя начислять $0.000300 как долг.»

## Критерии приёмки

- [ ] Модуль загружает реестр из файла конфигурации; если файла нет — берёт приложенный пример, где все маршруты выключены
- [ ] Приложенный пример конфигурации дополнен недостающими полями схемы и разбирается модулем без ошибок
- [ ] Имя файла реального конфига добавлено в `.gitignore`; сам пример остаётся без ключей и без секретов
- [ ] Для модели, которую Kie или PiAPI продаёт под тем же названием, ориентир считается по её точному тарифу и помечается как точная модель
- [ ] Для модели, которой в Kie или PiAPI нет, ориентир считается по явно названной другой модели — по умолчанию Kie GPT-6 Luna, запасная PiAPI GPT-5.6 Luna — и помечается как «другая модель»; выбор базовой линии берётся из конфигурации, а не зашит в код
- [ ] Если тарифа ориентира нет совсем, результат — «Тариф не подтверждён» без числа; ноль вместо суммы не подставляется никогда
- [ ] Ориентир для 5000 входных и 1000 выходных токенов по тарифу Kie GPT-6 Luna равен 0.000300 при точности 6 знаков
- [ ] Фактическое списание считается строго по тарифу провайдера-исполнителя; тариф другой модели в расчёт не попадает
- [ ] Подтверждённо бесплатный маршрут даёт факт ноль со статусом «бесплатный»; неопределённый исход — ноль не даёт, а помечается как неизвестное списание
- [ ] Суммы меньше одного цента не округляются в ноль ни в одном из двух расчётов
- [ ] Выбор маршрута по задаче и по режиму: в ручном режиме — запрошенный, в автоматическом — по роли; выключенный маршрут не выбирается, бесплатный — только при явном разрешении
- [ ] Каждый перечисленный случай закрыт тестом; прогон всех backend-тестов остаётся зелёным (242 на старте)
- [ ] Перед правкой сверены статус дерева, список worktrees и история с картой кода из отчёта аудита; расхождения зафиксированы, а не замалчаны
- [ ] Перед коммитом выведен блок плана, а после правки прогнана проектная проверка; новые тесты сначала показаны падающими
