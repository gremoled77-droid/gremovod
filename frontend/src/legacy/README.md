# legacy

Экраны и компоненты, скрытые до беты (решение владельца 18.10.2026): Рилсы, Сцена-демо, Агенты, старые галерея/очередь ChatGPT и раскадровка-демо.

Код не подключён к приложению и не проверяется `tsc` (папка исключена в `tsconfig.json`). Импорты внутри файлов указывают на `./…` из `src/` — при возврате экрана перенести файл обратно в `src/` и подключить через `screens.ts`. После беты: вернуть нужное в новом дизайне, остальное удалить.
