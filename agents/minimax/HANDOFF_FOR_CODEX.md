## Два дефекта, найденных и исправленных в самом инструменте Argon

Оба — ложные срабатывания, из-за которых инструмент отказывался ревьюить
собственный дифф. Оба закрыты регрессионными тестами.

1. **Ложное «бинарный файл».** Проверка искала подстроку `"Binary files "` во всём
   тексте диффа. Любой дифф, который просто *упоминает* эту строку,
   отклонялся как бинарный — включая дифф с исходником самого инструмента.
   Теперь бинарные файлы определяются опросом git (`diff --numstat`, где git
   сам помечает бинарный файл как `-\t-`).
2. **Ложное «секрет в диффе».** Детектор ловил фейковый ключ-заглушку
   `sk-…` внутри теста самого детектора. Детектор ослаблять нельзя, поэтому
   фикстура в тесте собирается из двух частей во время выполнения; написанный
   в temp-репозиторий текст не изменился, тест проверяет ту же строку.
