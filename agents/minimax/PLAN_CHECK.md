# План проверки связки mcode → GitHub → Argon

Проверки разбиты на гейты. Каждый следующий гейт запускается только после
явного подтверждения владельца. Платные шаги выделены отдельно.

Правило по умолчанию: **сначала бесплатно и офлайн, потом — по одному
подтверждённому платному запросу.** Никаких авто-ретраев и циклов.

## G1 — Ревью Argon LIVE (платно: 1 запрос, нужно подтверждение владельца)

Порядок обязателен:

1. `git diff --check` — пусто.
2. Бесплатные тесты G0 — PASS.
3. Офлайн-предпросмотр G0.5 — вручную прочитать дифф и payload.
4. Проверить: размер диффа ≤ 45 000 байт, файлов ≤ 12, нет бинарников,
   нет совпадений детектора секретов, SHA-256 зафиксирован.
5. Только после этого — **один** запрос с `--live` и ручным вводом
   `REVIEW <первые 12 символов digest>`.

Ошибка сети, HTTP 429, 5xx или таймаут — это **INCONCLUSIVE**, а не FAIL кода.
Авто-ретрая нет. Вывод Argon проверяется вручную по реальному коду; расхождения
с кодом фиксируются как ложные срабатывания, а не правится автоматически.

Ожидаемый расход: предыдущий аналогичный ревью стоил **4.1 кредита**.

## G2 — Опциональная проверка M Plan → Aider (нужен Subscription Key)

Это **не обязательно** для работы mcode: в самом MiniMax Code достаточно входа,
Subscription Key нужен только для сторонних инструментов.

1. Взять Subscription Key: https://platform.minimax.io/console/plan
   (это НЕ pay-as-you-go API Key; их нельзя менять местами).
2. Использовать **изолированную** конфигурацию — `agents/minimax/aider-minimax.example.env`.
   Ключ вводится только в переменную окружения этой сессии.
3. Маршрут M Plan (`https://api.minimax.io/anthropic`) и локальный KIE Proxy v2
   (`127.0.0.1:8767`) — **разные провайдеры**. Прокси обслуживает резервного
   исполнителя GPT-6 Sol и не перенастраивается.
4. Первый вызов — минимальный, с малым `max_tokens`.
5. Отдельно проверить поддержку `--reasoning-effort` и `--edit-format diff`
   на этой модели. Для M3.1-Flash параметр глубины — `output_config.effort`
   (`low|medium|high|xhigh|max`), а `none`/disabled модель отклоняет с 400.

Обязательные флаги: `--no-auto-commits --no-auto-test --no-cache-prompts
--cache-keepalive-pings 0`, без `--yes-always`.
