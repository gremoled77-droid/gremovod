# Протокол BETA — быстрое исследование реальных AI

Сначала проверяем идеи дёшево. Разрешено пропустить производственные A6/A7/A8 и ветки исправлений; **не разрешено** случайное повторное списание, скрытые ключи и выдача теста за принятый канон.

## Типовая серия экспериментов
1. **Text A1:** одна короткая завязка, max 200–300 output tokens, один Gateway Gemini Flash. Ожидаемый результат: 2 разных логлайна и комментарий, почему они разнятся. Проверка: только вручную, без «канон утверждён».
2. **Image:** один текущий Gateway image.generate, только если цена известна, н8н узел действительно поддерживает действие и нет запрещённого референса. Сохранить модель, размер, цену и ссылку на артефакт без публикации.
3. **Audio/TTS:** один короткий голосовой тест без клонирования реального человека без права, отделять voice/sfx/music.
4. **Video:** одна короткая генерация на 3–5 секунд с дешевым поддерживаемым Gateway node или Kie после отдельной настройки, **не** цикл исправлений.
5. **Вывод:** KEEP/CHANGE/REJECT, кратко почему, что передать позже Codex/Claude для production-подключения.

Техническая проверка только в рамках доступных фактов: текст, изображение, звук и кадры не подменяют друг друга. Результаты могут быть плохими — это нормально для поиска, но **не считать их acceptance**.

Нельзя использовать сохранённый A6/A7 Agent для траты Gateway credit: он использует внешний `Anthropic account`. Для первого теста — отдельный workflow с поддерживаемым Google Gemini node и Gateway.
