# GremoVOD BETA LAB — real AI experiments, independent of production

Дата: 2026-10-19. **Это экспериментальная ветка от main**, не часть цепочки PR #17 → #18 → #19. Не выполнять merge в main до отдельного ревью. В n8n отдельная папка **BETA Lab — experiments** внутри имеющегося проекта GremoVOD. Не создавать новый репозиторий, n8n-инстанс или независимую рабочую Studio SQLite.

## Цель

Проверять **гипотеза → реальный запрос к AI → результат → оценка → решение → запись в GitHub**. На бете нет сложных петель A6/A7/A8, восстановления UNKNOWN, мультимодального READY, обманной «канонизации», публикации и безопасного production автомата. Бета нужна для творческого и технического обучения, не может служить основным продакшеном.

Первые этапы: (1) короткая сценарная завязка и промпт A1 → (2) изображение по эталону, если есть разрешённый референс → (3) TTS → (4) короткое видео → (5) оценка человеком и решение. Каждая гипотеза — отдельный experiment_id, неавтоматическая кнопка запуска, сохранение IDs моделей и затрат. Платная видео/аудиогенерация — только после проверки цены, остатка и согласованного тестового задания. Kie.ai можно включить позже отдельным credential, **не смешивать баланс n8n Gateway с Kie**.

## Кошелёк BETA

Владелец указал номинальные $5 внутренних кредитов и цель сохранить **минимум $1**. Это **не подтверждённый текущий баланс**, поскольку наш n8n коннектор показывает покрытие Gateway, но **не значение счёта**. Текущий баланс нужно брать из n8n Cloud → Gateway credits, вкладка Balance; он **общий для всей инстанции**, включая другие workflows. Без реально доступного preflight balance API нельзя честно обещать автоматически остановиться ровно на $1.

Безопасная временная процедура: (i) посмотреть actual balance, (ii) запросить реальную цену/upper-bound модели, (iii) выполнить только один ручной вызов без автоматического retry, (iv) сверить после него фактический gateway spend и записать в EXPERIMENT_LOG.md. В обычных текстовых тестах рекомендуется ceiling **$0.10 за запрос** (целевой, а не гарантированный network hard cap). При балансе <=$1.25 **остановить эксперименты на Gateway**, чтобы оставить буфер. Автоматически не пополнять баланс, не включать external credential/fallback. Никогда не делать самостоятельного циклического вызова.

**Важная ловушка**: сохранённые n8n Agents A6/A7 пользуются credential `Anthropic account`, `isManaged:false`, то есть внешним ключом, **не** free Gateway. Их не использовать для беты за Gateway кредиты. Выбираем встроенные n8n AI nodes с **Use Gateway credits**, подтверждаем action allowlist. Текстовый `googleGemini` resource=text/operation=message поддерживается; обычные n8n Agents и Gateway node billing — разные механизмы. Секреты никогда не коммитить.
