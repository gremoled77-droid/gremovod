# GremoVOD

01_Персонажи — общие образы и референсы.
02_Локации — общие места действия.
03_Серии — номер, название и гость; внутри эпизоды-сцены, раскадровки и кадры.

Оригиналы студии сохранены в backend/library. Здесь находятся организованные копии с метаданными.

Практическое руководство: [кино, сценарий и производство](КИНО_И_ПРОИЗВОДСТВО.md). Применять при разработке сцен, раскадровке, монтаже и планировании генераций; шаблоны — заметки к существующим сущностям, не новый формат API.
