# KIE — второй провайдер (18.10.2026)

- `backend/kie.py`: отправка `createTask` и опрос `recordInfo` у api.kie.ai; ответы приводятся к форме PiAPI, поэтому оценка цены, токен подтверждения, бюджет, лента заданий и доставка в библиотеку общие.
- Ключ: `KIE_API_KEY` / `KIE_API_KEY.txt` или `kie-access/api-key.dpapi` (DPAPI текущего пользователя Windows). KIE есть в «Подключениях»; проверка баланса бесплатная.
- Модели `kie-seedream-5-pro` (basic 1K $0.035 / high 2K $0.07, +$0.0025 за референс после первого) и `kie-qwen-image-2.1` (1K $0.02 / 2K $0.04), обе image-to-image. Живая проверка 18.10.2026: Seedream basic (7 кредитов) и Qwen 1K (4 кредита), списание совпало с оценкой; запуск включён только для этих режимов, high/2K — после своей проверки.
- Привязка Task ID (`/api/jobs/{id}/recover`) пока только для PiAPI.

# Что изменено после ревью (15.10.2026)

Тесты: `cd model-studio; node --test` — 17 тестов, платных запросов нет. Проверено на Node 22 (Linux). Работа через настоящий PowerShell и KIE на Windows не проверялась.

## Исправления
1. **Падение процесса.** Фоновые `run`/`poll` обёрнуты (`bg`, `trySave`), добавлен обработчик `unhandledRejection`. Запись файлов идёт через `atomicWrite`: уникальный tmp-файл и повтор `rename` при EPERM/EBUSY/EACCES.
2. **Запуск с повреждённым файлом задачи.** Битый или неполный `<id>.json` пропускается с предупреждением, а не роняет сервер. При старте удаляются остатки `*.request.json`, `*.response.json` (в них base64 фото) и `*.tmp`.
3. **Зависшие imagegen-задачи.** Если исполнитель взял задачу и не обновляет `progress.json` дольше `STUDIO_STALE_MS` (10 мин), задача уходит в `error`, слот освобождается. Сбой при захвате (не EEXIST) тоже переводит задачу в `error`, а не оставляет её навсегда в памяти.
4. **Гонка в `/api/imagegen`.** Задача появляется в очереди только после записи референсов и `task.txt`.
5. **`.gitignore`.** Убрано `*-schema.json`: тесты читают эти файлы.
6. **Ошибки KIE.** Сообщение теперь содержит текст ответа KIE (например «KIE API error 402: Insufficient credits»). Таймаут, отсутствие PowerShell, ненастроенный ключ, чужой Windows-пользователь и нечитаемый ответ различаются (`kie-errors.mjs`).
7. **Токен после перезапуска.** При 403 страница обновляет токен и повторяет запрос один раз (403 приходит до обработки, платный запуск не дублируется).

## Автосохранение черновика
- Правка текста шлёт только текст и параметры; картинки отправляются, только если изменился их список или роли.
- Картинки лежат в отдельном `draft-images.json`, `draft.json` остаётся маленьким.
- Черновик с пустым промптом теперь сохраняется.
- Исправлен баг: `addEventListener('input',invalidate)` передавал событие как аргумент.
- «Подготовить промпты» отправляет только роли, без base64.

## Тесты
Новые: `kie-errors.test.mjs`, `draft.test.mjs`, `kie-flow.test.mjs` (успех, отказ, ошибка отправки, нехватка кредитов, перезапуск с taskId), `robustness.test.mjs`. Для них добавлен тестовый шов `STUDIO_KIE_MOCK` и модули в `support/`.
